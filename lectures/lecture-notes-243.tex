\subsection{Arc Length}


First, recall the definition of derivative:
\begin{align*}
  f'(x) 
  &:= \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}\\
\end{align*}
or equivalently,
\begin{equation*}
  f'(x) = \lim_{\tilde{x} \to x} \frac{f(\tilde{x})-f(x)}{\tilde{x}-x} = 
\end{equation*}
In other words, the derivative is obtained by computing 
\begin{equation*}
  \frac{\text{change in $y$-value}}{\text{change in $x$-value}}  = \frac{\Delta y}{\Delta x}
\end{equation*}
as $\Delta x \to  0$.


One of the central ideas in calculus is to approximate curvy things with flat things. For example, if
faced with a curve, approximate it with straight lines. For example,


\fl{Problem:} I am an ant, and I want to travel from $a$ to $b$ by walking on the graph of
$f(x)$. How far must I walk?

\Fl{Strategy:} Cheat a little: think of the ant walking in a bunch of straight lines that are pretty
close to the curve.

Here's the picture
\begin{center}
  \includegraphics[scale = 0.1]{images/arc-length-justification}
\end{center}

Here,
\begin{equation*}
  L = s_{1}+s_{2}+\ldots+s_{6}
\end{equation*}

where, for example,

\begin{align*}
  s_{4}
  &\approx \sqrt{\left( \Delta x \right)^{2} +\left( \Delta y \right)^{2} } &&\text{since the line
                                                                               segment length
                                                                               approximates the curve length}\\
  &= \sqrt{\left[ 1+\left( \frac{\Delta y}{\Delta x} \right)^{2}  \right]\left(\Delta x\right)^{2} }\\
  &= \sqrt{ 1+\left( \frac{\Delta y}{\Delta x} \right)^{2}  }\Delta x\\
  &\approx \sqrt{1+ \left( \frac{dy}{dx} \right)^{2} }dx &&\text{this holds when $\Delta x\approx
                                                            0$, so long as the curve is smooth}\\
  & = \sqrt{1 + \left[ f'(x) \right]^{2} }dx &&\text{by change of notation }
\end{align*}

\begin{theorem}[Arc length formula]
  \label{thm:arc-length-formula}
  Let $f$ be a differentiable function on the interval $[a,b]$, and assume that $f'$ is continuous on
  $[a,b]$. Then the arc length of $f$ from $x=a$ to $x=b$ is 
  \begin{equation*}
    \text{Arc Length} = \int_{a}^{b}\sqrt{1+\left[ f'(x) \right]^{2} }dx 
  \end{equation*}
\end{theorem}

\begin{example}[Arc length]
  \Fl{Problem:} Find the length of the curve defined by $f(x) = 2 x^{3/2}$, where $x$ ranges from $x=0$
  t0 $x=2$.

  \Fl{Solution:} $f'(x) = 3x^{\frac{1}{2}}$, so
  \begin{align*}
    \text{Arc length} 
    &= \int_{0}^{2} \sqrt{1+\left[ f'(x) \right]^{2} }dx\\
    &= \int_{0}^{2} \sqrt{1+9x }dx
  \end{align*}
  which we can solve with a $u$-substitution.
  
\end{example}
\begin{example}[Arc length]
  
  \label{ex:arc-length-sinh}
  
  \Fl{Problem:} Find the length of the curve defined by $f(x) = \frac{1}{2} \left( e^{x}+e^{-x} \right)$
  from $x=-1$ to $x=3$.

  \Fl{Solution:} We first claim that the following equality holds:
  \begin{equation}\label{eq:1}
    1+\left[ f'(x) \right]^{2}  = \left( \frac{e^{x}+e^{-x}}{2} \right)^{2}.
  \end{equation}
  This equality isn't obvious... it takes some work to deduce, which is shown below:
  \begin{proof}[Proof of \cref{eq:1}]
    Observe that $f'(x) = \frac{1}{2}(e^{x}-e^{-x})$. Therefore
    \begin{align*}
      1+\left[ f'(x) \right]^{2}
      &= 1 + \left[ \frac{1}{2}\left( e^{x}-e^{-x} \right)  \right]^{2}\\ 
      &= 1 + \frac{1}{4}\left( e^{2x} - 2 + e^{-2x} \right)\\ 
      &= \frac{1}{4} e^{2x} + \frac{1}{2} + \frac{1}{4}e^{-2x}  &&\text{expanding everything out } \\ 
      &= \frac{1}{4} \left( e^{2x}+2+e^{-2x} \right) &&\text{factor out $\frac{1}{4}$ }\\
      &= \frac{1}{4}\left( e^{x}+e^{-x} \right)^{2}\\ 
      &= \left( \frac{e^{x}+e^{-x}}{2} \right)^{2}. 
    \end{align*}
    This shows that \cref{eq:1} holds.
  \end{proof}

  Now with \cref{eq:1} in hand, everything simplifies really nicely when we apply the formula from
  \cref{thm:arc-length-formula}:
  \begin{align*}
    \text{Arc Length} 
    &= \int_{-1}^{3} \sqrt{1+\left[ f'(x) \right]^{2} }dx\\
    &= \int_{-1}^{3} \sqrt{\left( \frac{e^{x}+e^{-x}}{2} \right)^{2}  }dx\\
    &= \int_{-1}^{3} \frac{e^{x}+e^{-x}}{2}dx\\
    &= \frac{1}{2}\int_{-1}^{3} \left( e^{x}+e^{-x} \right) dx\\
    &= \frac{1}{2} \left[e^{x}-e^{-x} \right]_{x=-1}^{x=3}\\
    &= \frac{1}{2} \left[ \left( e^{3} - e^{-3} \right)  - \left( e^{-1}-e^{1} \right)  \right]\\
    &\approx 11.2
  \end{align*}  
\end{example}

\Fl{Tips}
\begin{itemize}
  \item Check that your answer is positive. Arc length is never negative.
  \item These problems are usually contrived so that you can actually do the integral. If the integral
  looks took hard, double check your work. Also, there might be a trick to the integral. 
\end{itemize}

\begin{example}[Warm up problem: Chain rule practice]
  Find the derviative of
  \begin{equation*}
    f(x) = \log\left(\frac{x^{2}}{\sin x} \right).
  \end{equation*}

  \textit{Solution:}
  \begin{align*}
    f'(x)
    &= \frac{d}{dx} \left[ \log\left(\frac{x^{2}}{\sin x} \right) \right] \\
    &= \frac{\sin x}{x^{2}}\frac{d}{dx} \left[ \frac{x^{2}}{\sin x} \right] &&\text{by the chain rule }\\ 
    &= \frac{\sin x}{x^{2}}\left( \frac{2x \sin x - x^{2}\cos x}{(\sin x)^{2}} \right) &&\text{by the quotient rule }\\ 
    &= \frac{2}{x}- \cot x &&\text{ after simplification.}
  \end{align*}
\end{example}

\begin{example}[Arc length]
  \Fl{Problem:} Let
  \begin{equation*}
    f(x) = \frac{x^{3}}{3} + \frac{1}{4x}+7,
  \end{equation*}
  for $1 \leq x \leq 2$.
  earlier examples.

  (\textit{Hint:} This problem is similar to \cref{ex:arc-length-sinh}.)

  \Fl{Solution:} We want to apply
  \cref{thm:arc-length-formula}. To do this, we first compute $1+\left[ f'(x) \right]^{2}$:
  \begin{align*}
    1+\left[ f'(x) \right]^{2}
    &= 1 + \left( x^{2} - \frac{1}{4}x^{-2} \right)^{2}\\
    &= x^{4}+\frac{1}{2} + \frac{1}{16}x^{-4}\\
    &= \left( x^{2}+\frac{1}{4}x^{-2} \right)^{2}. 
  \end{align*}
  The last step, where we write the equation as a perfect square, is kinda hard to see. But since we're
  familiar with \cref{ex:arc-length-sinh}, we know to possibly expect something like that.

  
  Now, we can apply the formul from \cref{thm:arc-length-formula}:
  \begin{align*}
    \text{Arc Length} 
    &= \int_{1}^{2} \sqrt{1+\left[ f'(x) \right]^{2} }dx\\
    &= \int_{1}^{2} \sqrt{ \left( x^{2}+\frac{1}{4}x^{-2} \right)^{2}  }dx\\
    &= \int_{1}^{2} x^{2}+\frac{1}{4}x^{-2} dx\\
    &= \left[ \frac{x^{3}}{3} - \frac{1}{4}x^{-1} \right]^{2}_{1}\\ 
    &= \left( \frac{8}{3}- \frac{1}{8} \right) - \left( \frac{1}{3}- \frac{1}{4} \right)\\  
    &\approx 2.46.
\end{align*}
\end{example}



\subsection{Parametric equations}
\textit{This section is based on chapter 10.1 in the textbook.}


I am an ant walking around the whiteboard, and I'm covered in ink. My path is described in the following
way:
\begin{itemize}
  \item The variable $t$ measures time. We start at $t=0$ and end at time $t=T_{\rm end}>0$.
  \item At each moment in time $t$, the number $x(t)$ represents my $x$-coordinate
  \item And the number $y(t)$ represents my $y$-coordinate.
\end{itemize}
The \demph{parametric equation} is the picture I draw by walking around the whiteboard.


\begin{definition}[Parametric Equations and Curves]
  \label{def:parametric-equations-and-curves}
  Let $I$ be an interval, and let $f:I \to \R$ and $g:I\to R$ be continuous functions whose domain is $I$. The set of all points of the form
  \begin{equation*}
    (x,y) = \left( f(t),g(t) \right) 
  \end{equation*}
  as $t$ varies over $I$, is the \demph{graph} of the \demph{parametric equations} $x=f(t)$ and $y=g(t)$. Here, $t$ is
  called the \demph{parameter}. A \demph{curve} is a graph along with the parametric equations that define it.
\end{definition}

\begin{notation}
  In ``set-builder notation,'' the graph of the parametric equations $x=f(t)$ and $y=g(t)$ is the set
  \begin{equation*}
    \left\{(f(t),g(t)) :  t \in  I \right\}.
  \end{equation*}
  For those unfamiliar with this notnation: the colon $`:'$ is read as ``such that'' and  $`\epsilon'$ is an abbreviation of ``is an element of''
\end{notation}

\begin{example}[Plotting parametric functions]
  Plot the graph of the parametric equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=t^{2} \\  y=t+1 \end{array}\right.
  \end{equation*}
 for $t$ in $I=[-2,2]$.

  \textit{Solution:}
  Start by plotting some points by making a table.

\end{example}

\subsection{Converting between parametric equations and Cartesian equations}
In contrast to parametric equations, an equation is said to be in \demph{rectangular form} (aka: \demph{Cartesian form})
if it takes the form $y=f(x)$ (or, less commonly, $x=f(y)$) for some function $f$. We've just seen in
\cref{ex:parametric-curve-with-singularity} that parametric equations offer significantly more flexibility when
graphing.

In fact, it is always possible to convert an equation from rectangular form into parametric form. We illustrate this
with the next example:
\begin{example}[Converting from rectangular form to parametric form]
  \label{ex:converting-from-rectangular-form-to-parametric-form}
  Consider the equation $y=x^{2}$, which is in rectangular form. This is an upward-opening parabola. There are many ways
  to represent this in parametric form. The simplest is with the parametric equations
  \begin{equation*}
    (x,y) = (t,t^{2})
  \end{equation*}
  where $t$ ranges over the interval $(-\infty,\infty)$.
\end{example}

\begin{example}[Converting from parametric form to rectangular form]
  \label{ex:converting-from-parametric-form-to-rectangular-form}
  Sometimes (but not always) we can also convert from parametric to rectangular form. Consider the parametric equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=t^{2} \\ y=7+5t \end{array}\right.
  \end{equation*}
  This is done by ``eliminating'' the parameter $t$, in the following way:

  Since $y=7+5t$, it follows that
  \begin{equation*}
    t = \frac{y-7}{5}.
  \end{equation*}
  Plugging this into $x=t^{2}$ gives
  \begin{align*}
    x 
    &= \left( \frac{y-7}{5} \right)^{2}\\
    &= \frac{1}{25}\left( y^{2} -14 y + 49 \right)\\ 
    &= \frac{1}{25}y^{2} - \frac{14}{25} y + \frac{49}{25}.
  \end{align*}
  This equation has the form $x=f(y)$, and therefore is in rectangular (i.e., Cartesian) form.
\end{example}

Here's another example
\begin{example}[Converting to Cartesian form: eliminating a parameter]

\begin{example}[Eliminating a parameter]
  \label{ex:eliminating-parameter}

  \end{equation*}

  \textit{Before we start this problem, let's observe that these parametric equations trace out an ellipse

    Cartesian form by eliminating the paramter $t$, we should expect to get the equation of this ellipse. }

  First, solve for $\sin(t)$ and $\cos(t)$:

  \begin{equation}\label{eq:9}
    \sin(t) = \frac{y-1}{2} \quad \text{and} \quad \cos(t) = \frac{x-3}{4}
  \end{equation}

  \begin{equation*}
    \cos^{2}(t) + \sin^{2}(t)  = 1.
  \end{equation*}
  Substituting in the formulas from \cref{eq:9} gives:
  \begin{equation*}
    \left( \frac{x-3}{4} \right)^{2} + \left( \frac{y-1}{2} \right)^{2}=1,
  \end{equation*}
  or equivalently
  \begin{equation*}
    \frac{1}{16}(x-3)^{2}+\frac{1}{4}(y-1)^{2} = 1.
  \end{equation*}
  This is indeed the equation of an ellipse, with center $(3,1)$ and with horizontal and vertical axes 4 and 2

\end{example}

  In \cref{ex:eliminating-parameter,ex:an-ellipse}, we saw equations of ellipses. In general the parametric equations
  for an ellipse take the form
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x= a \cos(t)+h \\ y = b\sin(t)+k \end{array}\right.
  \end{equation*}
  where $(h,k)$ is the center of the ellipse, $a$ is the horizontal radius, and $b$ is the vertical radius.

  \begin{equation*}
    \frac{1}{a^{2}}(x-h)^{2} + \frac{1}{b^{2}}(h-k)^{2} = 1.
  \end{equation*}
\end{remark}

\subsection{Smoothness of parameterized curves}
\begin{definition}[Smooth]
  A curve $C$ defined by the parametric equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=f(t) \\ y=g(t) \end{array}\right.
  \end{equation*}
  is \demph{smooth} on an interval $I$ if $f'$ and $g'$ are continuous on $I$ and not simultaneously zero on the
  interior of $I$. A curve is \demph{piecewise smooth} on $I$ if $I$ can be partitioned into subintervals such that $C$
  is smooth on each subinterval.
\end{definition}

\begin{example}[A non-smooth curve]
  \label{ex:non-smooth-curve}
  Consider the equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x(t):=\cos^{3}(t) \\ y(t) := \sin^{3}(t) \end{array}\right.
  \end{equation*}
  with $t$ in $I=[0,\infty)$. This has graph
  \begin{center}
    \includegraphics[scale=.2]{images/astroid}
  \end{center}
  This sure doesn't look smooth, because it has pointy cusps! Let's show that using the definition.

  First, differentiate:
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x'(t) = -3\cos^{2}(t)\sin(t) \\ y'(t) = 3\sin^{2}(t)\cos(t) \end{array}\right.
  \end{equation*}
  Are these functions ever simultaneously zero? Yes. For example, when $t=0$. Or
  $t=\frac{\pi}{2},\pi,\frac{3\pi}{2},2\pi,\ldots$.
  Therefore the curve is not smooth (although it is piecewise smooth).
\end{example}
\subsection{Tangent and normal lines to parameterized curves}

\begin{question}
  Suppose we have a parametric system of equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=f(t) \\ y=g(t) \end{array}\right.
  \end{equation*}
  for $t\in I$. How can we find the derivative $\frac{dy}{dx}$?
\end{question}

The answer to this question is the following important idea: 
\begin{equation}\label{eq:dydx-of-parametric-curve}
  \frac{dy}{dx}(t) = \frac{g'(t)}{f'(t)}
\end{equation}
provided that the following two assumptions hold:
\begin{itemize}
  \item $f$ and $g$ are both differentiable (otherwise $f'$ and $g'$ wouldn't exist)
  \item $f'(t)\neq 0$ (otherwise we'd have divsion by zero)
\end{itemize}

\begin{definition}[Tangent Line and Normal Line]
  \label{def:tangent-line-and-normal-line}
  Let $C$ be a curve parameterized by
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=f(t) \\ y=g(t) \end{array}\right.
  \end{equation*}
  where $f,g:I\to \R$ are differentiable functions. Let $s$ be a point in $I$.
  \begin{itemize}
    \item The \demph{tangent line} to $C$ at $t=s$ is the line
    \begin{equation*} y-g(s) = \frac{g'(s)}{f'(s)}\left(x-f(s)\right),
    \end{equation*} provided that $f'(s)\neq 0$. 
    \item The \demph{normal line} to $C$ at $t=s$ is the line
    \begin{equation*}
      y-g(s) = -\frac{f'(s)}{g'(s)}\left(x-f(s)\right),
    \end{equation*}
    provided that $g'(s)\neq 0$. 
  \end{itemize}
\end{definition}
\begin{remark}
  Both the tangent line and the normal line pass through the point $(x,y)=(f(s),g(s))$, which lies on the curve. The
  only difference is their slope. The tangent line has slope
  \begin{equation*}
    m_{\rm tan} = \frac{g'(s)}{f'(s)} = \frac{dy}{dx}(s)
  \end{equation*}
  while the normal line has slope
  \begin{equation*}
    m_{\rm norm}=-\frac{f'(s)}{g'(s)} = -\frac{1}{\frac{dy}{dx}(s)}.
  \end{equation*}
  Since
  \begin{equation*}
    m_{\rm tan} = -\frac{1}{m_{\rm norm}}
  \end{equation*}
  it follows that the two lines are perpendicular to each other: the tangent line lies tangent to the curve, while the
  normal line is perpendicular to it.
\end{remark}

\begin{example}[Tangent and normal lines]
  \label{ex:tangent-and-normal-lines}
  Let $C$ be the curve defined by
  \begin{equation}\label{eq:10}
    \left\{ \begin{array}{l@{}l} x(t) = 5t^{2}-6t+4 \\ y(t) = t^{2}+6t-1 \end{array}\right.
  \end{equation}
  \noindent\textit{Problem:}  Find the tangent line and normal line to $C$ at $t=3$.
  
  \noindent\textit{Solution:} For this problem, we have $f(t) = 5t^{2}-6t+4$ and $g(t) = t^{2}+6t-1$.

  Before we start, this is the picture:

  \begin{center}
    \includegraphics[scale=.3]{images/tangent-normal-lines}
  \end{center}

  Differentiate:
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} f'(t)  = 10t -t \\ g'(t) = 2t+6  \end{array}\right.
  \end{equation*}

  Therefore
  \begin{equation}\label{eq:11}
    \frac{dy}{dx}(t) = \frac{f'(t)}{g'(t)}=\frac{2t+6}{10t-6}.
  \end{equation}
  Important note: $\frac{dy}{dx}$ is a function of $t$. It is not a function of $x$!

  At the point $t=3$, we have:
  \begin{itemize}
    \item $(x,y)=(31, 26)$ (by \cref{eq:10})
    \item The slope is $\frac{dy}{dx}(3) = \frac{1}{2}$ (by \cref{eq:11})
  \end{itemize}
  Combining these two facts, and using \cref{def:tangent-line-and-normal-line}, we conclude that the tangent line is
  \begin{equation*}
    y-26 = \frac{1}{2}(x-31)
  \end{equation*}
  (this is the equation of a line in point-slope form). Here, we have $m_{\rm tan}=\frac{1}{2}$. The slope of the normal line is
  always $-\frac{1}{m_{\rm tan}}$, which is $-2$. We conclude that the normal line is
  \begin{equation*}
    y-26 = -2(x-31).
  \end{equation*}
\end{example}

\subsection{Arc Length of parametrized curves}
\begin{theorem}[Arc Length of Parametric Curves]
  \label{thm:arc-length-parametric-curves}
  Let
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=f(t) \\ y=g(t) \end{array}\right.
  \end{equation*}
  be a parametric equations defined on an interval $I=[a,b]$. Assume that $f$ and $g$ are differentiable
  an that $f'$ and $g'$ are continuous on $[a,b]$. Also assume that the graph traces itself only once.
  The arc length of the curve is
  \begin{equation*}
    L = \int_{a}^{b}\sqrt{f'(t)^{2}+g'(t)^{2}}dt. 
  \end{equation*}
\end{theorem}
\begin{remark}
  These integrals are often hard to compute.
\end{remark}

\begin{example}[Arc length of a circle]
  \label{ex:arc-length-circle}

  Consider the circle paramterized by the equationss
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=3\cos t \\ y = 3\sin t \end{array}\right.
  \end{equation*}
  where $t$ ranges over the interval $[0,2\pi]$. What is the arc length?

  \textit{Solution:} Here $f(t) = 3\cos(t)$ and $g(t) = 3\sin(t)$. Using the formula from \cref{thm:arc-length-parametric-curves}
  \begin{align*}
    L 
    &= \int_{0}^{2\pi} \sqrt{f'(t)^{2}+g'(t)^{2}}dt\\
    &= \int_{0}^{2\pi} \sqrt{(-3\sin t)^{2}+(3\cos t)^{2}}dt\\
    &= 3 \int_{0}^{2\pi} \sqrt{\sin^{2}(t)+\cos^{2}(t)}dt\\ 
    &= 3 \int_{0}^{2\pi} 1 dt &&\text{since $\sin^{2}(t)+\cos^{2}(t) =1$}\\ 
    &= 6\pi.
  \end{align*}
  Taking a step back. What was this question really asking? It was asking for the circumference of a circle with radius
  $3$ (since that's the curve traced out by the equations). Using the formula
  \begin{equation*}
    \text{circumference} = 2\pi (\text{radius}),
  \end{equation*}
  our answer $6\pi^{2}$ makes sense.
\end{example}

\begin{example}[Arc length]
  What is the arc length of the curve parameterized by the equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l}
        x(t) = \frac{7}{3}t^{3}+t \\
        y(t) = \frac{2}{3}\left( 2t^{2}+\frac{1}{4} \right)^{3/2}  \end{array}\right.
  \end{equation*}
  for $0 \leq t \leq 2$?
  
  \noindent \textit{Solution:}

  Step 1. Compute $x'(t)$ and $y'(t)$:
  \begin{equation*}
    x'(t) = 7t^{2}+1
    \quad \text{and} \quad 
    y'(t) = \left(2t^{2}+\frac{1}{4}\right)^{\frac{1}{2}}\cdot 4t.
  \end{equation*}

  Step 2. Compute $\left[ x'(t) \right]^{2}+\left[ y'(t) \right]^{2}$ and simplify.
  \begin{align*}
    \left[ x'(t) \right]^{2}+\left[ y'(t) \right]^{2} 
    &=\left[ 7t^{2}+1 \right]^{2} + \left[ \left( 2t^{2}+\frac{1}{4} \right)^{\frac{1}{2}}\cdot 4t  \right]^{2}\\  
    &= 49 t^{4} + 14 t^{2}+1 + \left( 2t^{2}+\frac{1}{4} \right)\cdot 16t^{2}\\ 
    &= 49t^{4}+ 14 t^{2} + 1 + 32 t^{4}+ 4 t^{2}\\
    &= 81 t^{4}+ 18 t^{2}+1.
  \end{align*}

  Step 3. Recognize that you've got a perfect square:
  \begin{equation*}
    81 t^{4}+ 18 t^{2}+1 = \left( 9t^{2}+1 \right)^{2}
  \end{equation*}

  \quad \textit{(Step 3 doesn't always happen, but it's \textit{really} nice when it does!)}
  

  Step 4. Plug what you get back into the formula from \cref{thm:arc-length-parametric-curves}:

  \begin{align*}
    \text{Arc Length} 
    &= \int_{0}^{2}  \sqrt{\left[ x'(t) \right]^{2} + \left[ y'(t) \right]^{2}  } dt\\
    &= \int_{0}^{2} \sqrt{ \left( 9t^{2}+1 \right)^{2} }dt\\ 
    &= \int_{0}^{2}  (9t^{2}+1) dt\\
    &= \left[ 3t^{3} + t \right]^{2}_{0}\\ 
    &= 26.
  \end{align*}
  
  We conclude that the arc length is 26.
\end{example}

\Fl{With parameterized curves, the story is no different, but we'll need to learn how to compute the second derivative
  $\frac{d^{2}y}{dx^{2}}$, as we now show.}

Consider a curve
\begin{equation*}
  \left\{ \begin{array}{l@{}l} x = f(t) \\ y= g(t) \end{array}\right.
\end{equation*}
so that $f,g$ are twice differentiable on the inteval $I$ and $f'(t)\neq 0$ on $I$.

We have already seen how to compute
\begin{equation*}
  \frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{g'(t)}{f'(t)}.
\end{equation*}

What about $\frac{d^{2}y}{dx^{2}}$? The formula is:

\begin{equation}\label{eq:2nd-derivative-for-parameterized-curves}
  \frac{d^{2}y}{dx^{2}} = \frac{\frac{d}{dt}\left[ \frac{dy}{dx} \right] }{\frac{dx}{dt}}= \frac{\frac{d}{dt}\left[ \frac{dy}{dx} \right] }{f'(t)}
\end{equation}
\begin{example}[Concavity of a parameterized curve]
  Let $C$ be the curve defined by the parametric equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x(t) = \frac{1}{2}t^{2}+\frac{1}{2} \\ y(t) = t-t^{3} \end{array}\right.
  \end{equation*}
  \begin{enumerate}[(a)]
    \item Find the tangent line to $C$ at $t=1$.
    \item For what values of $t$ is the curve convex up? For what values is it concave down?
    \item At what points $(x,y)$ does the curve have a horizontal tangent line? Vertical tangent line?
  \end{enumerate}

  \Fl{Solution to (a):} To apply the line formula $y-y_{0} = m(x-x_{0})$, we need two things: (1) the
  point $(x(1),y(1))$ and the slope at $t=1$.

  First observe that
  \begin{equation*}
    (x(1),y(1)) = (1,0)
  \end{equation*}

  Second, to compute the slope:
  \begin{align*}
    \label{eq:2}
    \frac{dy}{dx} 
    &= \frac{dy/dt}{dx/dt}\nonumber\\
    &= \frac{\frac{d}{dt}\left[ t-t^{3} \right] }{\frac{d}{dt}\left[ \frac{1}{2}t^{2}+\frac{1}{2} \right] }\nonumber\\
    &= \frac{1-3t^{2} }{t }
  \end{align*}
  So when $t=1$, we have
  \begin{equation*}
    \frac{dy}{dx}(t) = \frac{dy}{dx}(1) = -2
  \end{equation*}
  Therefore by the line formula $y-y_{0}= m(x-x_{0})$, we conclude that the tangent line at $t=1$ has
  equation
  \begin{equation*}
    y-0 = -2(x-1)
  \end{equation*}
  or equivalently,
  \begin{equation*}
    y = -2x+2.
  \end{equation*}

  \Fl{Solution to (b).} Here, our approach is to compute the second derivatve and then check when it is
  positive or negative, as this is sufficient to determine whether the curve is concave up or concave
  down.

  To compute the second derivative we'll use the formula:
  \begin{equation*}
    \frac{d^{2}y}{dx^{2}} = \frac{\frac{d}{dt}\left[ \frac{dy}{dx} \right] }{\frac{dx}{dt}}.
  \end{equation*}
  Now, in part (a) we've already computed some components of the above equation. Specifically, we know
  that $\frac{dy}{dx} = \frac{1-3t^{2}}{t}$ and $\frac{dx}{dt} = t$. Plugging these in, we get
  \begin{equation*}
    \frac{d^{2}y}{dx^{2}} = \frac{\frac{d}{dt}\left[ \frac{1-3t^{2}}{t} \right] }{t}
  \end{equation*}
  doing the derivative (e.g., using the quotient rule) and simplifying gives
  \begin{equation*}
    \frac{d^{2}y}{dx^{2}} = - \frac{1+3t^{2}}{t^{3}}
  \end{equation*}
  One can check that this function is NEGATIVE when $t<0$, and POSITIVE when $t>0$. To see this, we can
  either solve the inequality
  \begin{equation*}
    -\frac{1+3t^{2}}{t^{3}}>0
  \end{equation*}
  or we can look at the graph of the second derivative:
  \begin{center}
    \includegraphics[scale=.2]{images/second-derivative-plot}
  \end{center}


  \Fl{Solution to (c).} To find the horizontal tangent lines, we need check when $\frac{dy}{dx}(t) = 0$.
  To find the vertical tangent lines, we check when $\frac{dy}{dx}(t) = \pm \infty$ or undefined.

  In part (a) we computed 
  \begin{equation}\label{eq:3}
    \frac{dy}{dx} = \frac{1-3t^{2}}{t}.
  \end{equation}
  By inspection, this is undefined when $t=0$, since there is a division by zero in that case. Therefore
  the tangent line is vertical when $t=0$, which occurs at the point
  \begin{equation*}
    \left(x(0),y(0)\right) = \left(\frac{1}{2},0\right).
  \end{equation*}
  On the other hand, we see from \cref{eq:3} that $\frac{dy}{dx}(t) = 0$ (i.e., the tangent line is
  horizontal) if and only if
  \begin{equation*}
    1-3t^{2}=0
  \end{equation*}
  or equivalently, when $t=\pm \frac{1}{\sqrt{3}}$. At what points does this occur?
  \begin{itemize}
    \item If $t= \frac{1}{\sqrt{3}}$, then the point is
    \begin{equation*}
      \left(x\left(\frac{1}{\sqrt{3}}\right), y\left(\frac{1}{\sqrt{3}}\right) \right)= \left( \frac{2}{3}, \frac{2}{3 \sqrt{3}} \right)
    \end{equation*}
    \item If  $t=-\frac{1}{\sqrt{3}}$, then the point is
    \begin{equation*}
      \left(x\left(-\frac{1}{\sqrt{3}}\right), y\left(-\frac{1}{\sqrt{3}}\right) \right)= \left( \frac{2}{3}, -\frac{2}{3 \sqrt{3}} \right) 
    \end{equation*}
  \end{itemize}
  We conclude that the curve $C$ has a horizontal tangent line at the points $\left( \frac{2}{3},
    \frac{2}{3 \sqrt{3}} \right)  $ and $\left( \frac{2}{3}, -\frac{2}{3 \sqrt{3}} \right) $, and a
  vertical tangent line at the point $\left( \frac{1}{2},0 \right)$. This answers part (c).
\end{example}

\begin{theorem}[Key identities for converting between polar and rectangular coordinates]
  \label{thm:key-identities-for-converting-between-polar-and-rectangular-coordinates}
  If $(r,\theta)$ is a point in polar coordinates, the rectangular coordinates
  are given by
  \begin{equation}\label{eq:polar-key-sincos-identity}
    x = r\cos \theta \quad \text{and} \quad y = r\sin \theta
  \end{equation}
  On the other hand, given a point $(x,y)$ in rectangular coordinates, the polar
  coordinates are determined by the identities
  \begin{equation}\label{eq:polar-key-cart-identities}
    r^{2} = x^{2}+y^{2} \quad \text{and} \quad \tan \theta = \frac{y}{x}
  \end{equation}
\end{theorem}

\cref{eq:polar-key-sincos-identity} allows us to find the Cartesian coordinates
of a point when the polar coordinates are known. More generally, can use the
identities in
\cref{thm:key-identities-for-converting-between-polar-and-rectangular-coordinates}
to convert between coordinate systems, as shown in the next examples.

\subsection{Converting between Polar to Cartesian form}
\begin{example}[Cartesian $\implies$ Polar ]
  Find a polar equation of the form $r = f(\theta)$ for the
  curve represented by the Cartesian equation $x=-2y^{2}$.

  \Fli{Solution:} Use
  $x=r\cos(\theta)$ and $y=r\sin(\theta)$:
  \begin{align*}
    r\cos(\theta) 
    &= -2 \left( r\sin(\theta) \right)^{2}\\
    &= -2 r^{2}\sin^{2}(\theta).
  \end{align*}
  Divide both sides by $r$:
  \begin{equation*}
    \cos(\theta) = -2r \sin^{2}(\theta).
  \end{equation*}
  Solve for $r$:
  \begin{equation*}
    r = -\frac{\cos(\theta)}{2\sin^{2}(\theta)}
  \end{equation*}
\end{example}


\begin{example}[Polar $\implies$ Cartesian]
  Find a Cartesian equation for the polar curve $r=2\cos(\theta)$.

  \Fli{Solution:} By \cref{eq:polar-key-sincos-identity}, we know that 
  \begin{equation*}
    x= r\cos(\theta).
  \end{equation*}
  Multiply both sides of our original equation by $r$:
  \begin{equation*}
    r^{2} = 2r\cos(\theta)
  \end{equation*}
  Thus
  \begin{equation*}
    r^{2} = 2x.
  \end{equation*}
  By \cref{eq:polar-key-cart-identities}, we know that $r^{2} = x^{2}+y^{2}$.
  Therefore
  \begin{equation*}
    x^{2}+y^{2} = 2x.
  \end{equation*}
  Completing the square gives
  \begin{equation*}
    (x-1)^{2} + y^{2} =1
  \end{equation*}
  This is a circle of radius 1 with center at $(1,0)$. 
\end{example}

\subsection{Finding $\frac{dy}{dx}$ with polar functions}
No matter what coordinate system we use, the slope of a tangent line is always given by the quantity $\frac{dy}{dx}$.

We've seen how to compute that in other contexts. How do we compute $\frac{dy}{dx}$ when our equation is
a polar function of the form $r = f(\theta)$?

As a function of $\theta$, the $(x,y)$-coordinates are
\begin{equation*}
  x=f(\theta)\cos(\theta), \quad y = f(\theta)\sin(\theta).
\end{equation*}
By the product rule,
\begin{equation*}
  \frac{dx}{d\theta} = f'(\theta)\cos(\theta)-f(\theta)\sin(\theta) \quad \text{and} \quad  \frac{dy}{d\theta} = f'(\theta)\sin(\theta) + f(\theta)\cos(\theta).
\end{equation*}
Certainly, we must have:
\begin{equation*}
  \frac{dy}{dx} = \frac{dy/d\theta}{dx/d\theta}.
\end{equation*}

  \boxed{
    \frac{dy}{dx} = \frac{f'(\theta)\sin(\theta) + f(\theta)\cos(\theta)}{f'(\theta)\cos(\theta)-f(\theta)\sin(\theta)}
  }
\end{equation*}

\subsection{Areas enclosed by polar graphs}

Next lecture will discuss computing areas enclosed by polar graphs. The formula for this is the following


A \demph{sector} is the following
\begin{center}
  \includegraphics[scale=1]{images/sector}
\end{center}
\begin{theorem}[Area of a sector]
  The area of a sector with angle $\theta$ is
  \begin{equation*}
    \text{area } = \frac{1}{2}\theta r^{2}
  \end{equation*}
\end{theorem}
For example, if $\theta=360^{\circ} = 2\pi$, then
\begin{equation*}
  \text{area } = \pi r^{2},
\end{equation*}
which is the formula for the area of a circle.

\begin{theorem}\label{thm:polar-area-theorem}
  If $r=f(\theta)$ and $f$ is a continuous and \textbf{nonnegative} function on the interval $[\alpha,\beta]$, where $0
  \leq \beta-\alpha \leq 2\pi$ then the area of the region bounded by the
  lines $r =f(\theta)$ and $\theta=a$ and $\theta = b$ is
  \begin{equation*}
    \text{Area} = \frac{1}{2}\int_{\alpha}^{\beta}r^{2}d\theta =  \frac{1}{2} \int_{\alpha}^{\beta}\left[ f(\theta) \right]^{2}d\theta   
  \end{equation*}
\end{theorem}
\begin{remark}
  It's really important that you check that the conditions $0 \leq \beta - \alpha \leq 2\pi$ and
  nonnegativity of $f$. Otherwise cancelletion or double counting of regions may occur, resulting in the
  integral not actually equalling the area.
\end{remark}

Throughout we will use the following useful proposition.

\begin{proposition}[Useful integrals]
  \label{prop:useful-integrals}
  It holds that
  \begin{align*}
    \int \cos^{2}(\theta)d\theta  &= \frac{\theta}{2}+\frac{\sin(2\theta)}{4}+C\\
    \int \sin^{2}(\theta)d\theta  &= \frac{\theta}{2}-\frac{\sin(2\theta)}{4}+C
  \end{align*}
\end{proposition}
The integrals of \cref{prop:useful-integrals} can be computed using the power-reduction identities
$\cos^{2}(\theta) = \frac{1+\cos(2\theta)}{2}$ and $\sin^{2}(\theta) = \frac{1-\cos(2\theta)}{2}$.
 
\begin{example}[Area of region enclosed by polar coordinates]
  \label{ex:area-region-enclosed-polar-coordinates}
  Consider the polar function
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} r = 4 \sin(3\theta) \\ 0 \leq \theta \leq \frac{\pi}{3}\end{array}\right.
  \end{equation*}
  This is a petal. As $\theta$ ranges from 0 to $\frac{\pi}{3}$, the curve loops counterclockwise from
  the origin back to the origin. To see why, think about the motion of a particle whose trajectory is
  traced out by $(r,\theta) = (\sin(3\theta),\theta)$. At $\theta=0$, the particle starts at the origin.
  When $\theta = \frac{\pi}{6}$, the particle's distance from the origin is maximized. When
  $\theta=\frac{\pi}{3}$, the particle is back at the origin. This traces out exactly the full petal.. So
  we will integrate over the interval $0 \leq \theta \leq \frac{\pi}{3}$.

3D space is denoted by the symbol $\R^{3}$. A point in 3D space is specified as an ordered triple

Many familiar equations take on new meaning in 3D space, compared to 2D space.

\begin{itemize}
  \item Consider the equation
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x^{2}+y^{2} =1 \\ z=3 \end{array}\right.
  \end{equation*}
  This is a unit circle floating 3 units above the $xy$-plane.

  On the other hand, the equation
  \begin{equation*}
    x^{2}+y^{2}=1
  \end{equation*}
  imposes no restriction on the value of $z$. Consequently, this is the equation of a (hollow) cyclinder.

  \item The equation
  \begin{equation*}
    x^{2}+y^{2}+z^{2}=1
  \end{equation*}
  is the equation of a sphere with radius 1 centered at the origin.

\end{itemize}

\begin{example}[Scaling a vector]
  In general, one can \demph{scale} a vector by multiplying it by a number. Let
  \begin{equation*}
    \vec{v} = \left\langle -2,4,4 \right\rangle 
  \end{equation*}
  Then $\vec{v}$ has length
  \begin{equation*}
    \left| \vec{v} \right| = \sqrt{(-2)^{2}+(4)^{2}+(4)^{2}} = \sqrt{ 4+16+16} = \sqrt{36} = 6.
  \end{equation*}
  If we scale $\vec{v}$ by a factor of $3$, then the resulting vector is
  \begin{equation*}
    \vec{u} = 3 \vec{v} = \left\langle -6,12,12 \right\rangle 
  \end{equation*}
  which has three times the length:
  \begin{equation*}
    \left| \vec{u} \right| = \sqrt{(-6)^{2}+(12)^{2}+(12)^{2}} = \sqrt{ 36 + 144 + 144} = \sqrt{324} = 18.
  \end{equation*}
  Similarly, if I scale a vector by $2$, then its length gets doubled. If I scale a vector by $1/2$, its
  length gets halved.
\end{example}

\begin{example}[Distance between points]
  The formula for computing the distance between two points in 3D space is related to the formula for
  computing the length of a 3D vector. Say you have a fly which starts at point $P:=(x_{1},y_{1},z_{1})$,
  flies around around a bit, and then terminates at point $Q:=(x_{2},y_{2},z_{2})$. Then the
  \demph{displacement vector} is
  \begin{equation*}
    \overrightarrow{PQ} = \left\langle x_{2}-x_{1},y_{2}-y_{1},z_{2}-z_{1} \right\rangle 
  \end{equation*}
  You can think of this as an arrow drawn from the fly's starting position $P$ to its ending position
  $Q$. The distance between points $P$ and $Q$ is nothing other than the magnitude of this vector.
  %
  Therefore, distance between two points $(x_{1},y_{1},z_{1})$
  and $(x_{2},y_{2},z_{2})$ is
  \begin{equation*}
    \text{distance } 
    = \sqrt{\left( x_{2}-x_{1} \right)^{2} + \left( y_{2}-y_{1} \right)^{2} + \left( z_{2}-z_{1} \right)^{2}}.
  \end{equation*}
  For example, say the fly starts at $(3,2,9)$ and ends at $(2,-2,1)$. The distance between these two
  points is
  \begin{align*}
    \text{distance }
    &= \sqrt{\left( 3-2 \right)^{2}+\left( 2-(-2) \right)^{2}+(9-1)^{2}  }\\
    &= \sqrt{1^{2}+4^{2}+8^{2}}\\
    &= \sqrt{1+16+64}\\
    &= \sqrt{81}\\
    &=9.
  \end{align*}
\end{example}

\subsection{Connection to Physics: Force}
Vectors are used to represent \demph{force}, understood in physics as a physical interaction (e.g. a
push or a pull) which causes (or can cause) change in an object's motion, shape, or resting position.
Force has magnitude (i.e., length) and a direction.
% 
\begin{example}[Forces]
  If you are floating in the ocean, you get pushed around by lots of forces: (1) gravity, (2) waves, (3)
  current, (4) wind, (5) forces created by your own motion, (6) buoyant force, and others. Each of these
  forces can be modeled by a vector. The magnitude of the vector indicates the ``strength'' of the
  corresponding force. For example, wind doesn't exert much force on a swimmer, so that vector might be
  tiny. By comparison the vector for current might be very large.

  The \demph{resultant force} is the sum of these vectors, and determines your net motion.
\end{example}

Force is measured in \textbf{Newtons}, denoted $N$. How much is one $1N$? It's approximately equal to the
weight that you feel pushing down on your hand when you hold up a stick of butter. (Note: \textit{weight}
is a force).

Technically, $N=\mathrm{kg}\cdot \mathrm{m/s^{2}}$. In words one Newton is the amount of force needed to
accelerate one \textrm{kg} of mass at one meter per second per second (e.g., so that after two seconds
the mass is moving at two meters per second). This is a bit confusing at first, as it is the product of a
unit of mass (\textrm{kg}) with a unit of acceleration $(\mathrm{m/s^{2}})$. This is due to
\textbf{Newton's Second Law}, which states
\begin{equation*}
  \text{force} = \text{mass}\times \text{acceleration}.
\end{equation*}




\subsection{Dot Product}

\begin{definition}[Dot Product]
  Let $\vec{a}$ and $\vec{b}$ be vectors. The \demph{dot product} of $\vec{a}$ and $\vec{b}$ is
  \begin{equation*}
    \vec{a}\cdot \vec{b} = a_{1}b_{1}+ a_{2}b_{2}+ a_{3}b_{3}.
  \end{equation*}
  A similar definition holds for vectors of length $2$ (or $10$, or $35$, etc).
\end{definition}

\begin{example}
  Let $\vec{a} = \left\langle 1,-4,1 \right\rangle$, $\vec{b} = \left\langle 0,2,-2 \right\rangle$, and
  $\vec{c} = \left\langle 5,2,1 \right\rangle $
  Then
  \begin{equation*}
    \vec{a} \cdot \vec{b} = (1)(0)+ (-4)(2)+(1)(-2) = 0-8-2 = -10.
  \end{equation*}
  Similarly,
  \begin{equation*}
    \vec{a}\cdot \vec{c} = 5-8+1 = -2
    \quad \text{and} \quad
    \vec{b} \cdot \vec{c} = 0 +4-2 = 2.
  \end{equation*}
\end{example}

The dot product has important geometric meaning, which we will explore. But first, let's make some
observations about the properties of the dot product, summarized in the following proposition:

\begin{proposition}[Dot Product Properties]
  Let $\vec{a}=(a_{1},a_{2},a_{3})$, and $\vec{b} = (b_{1},b_{2},b_{3})$ and
  $\vec{c}=(c_{1},c_{2},c_{3})$ be vectors. Then the following properties hold
  \begin{itemize}
    \item $\vec{0} \cdot \vec{a} = 0$
    \item $\vec{a}\cdot \vec{b} = \vec{b} + \vec{a}$ 
    \item $\vec{a}\cdot \vec{a} = a_{1}^{2}+a_{2}^{2}+a_{3}^{2} = |\vec{a}|^{2}$ 
    \item $\vec{a}\cdot (\vec{b}+\vec{c}) = \vec{a}\cdot \vec{b} + \vec{a} \cdot\vec{c} $
  \end{itemize}
\end{proposition}

The next theorem connects the dot product of two vectors with the angle between them.

\begin{theorem}[The dot-product/angle relationship]
  \label{thm:dot-productangle-relationship}
  Let $\vec{a}$ and $\vec{b}$ be vectors. Suppose that the angle between $\vec{a}$ and $\vec{b}$ is
  $\theta$. Then
  \begin{equation*}
    \vec{a}\cdot \vec{b} = | \vec{a} | |\vec{b}| \cos(\theta).
  \end{equation*}
\end{theorem}
Let's try to unwrap some implications of this theorem:
\begin{itemize}
  \item When $\theta$ is an acute angle, that means $0 < \theta < \frac{\pi}{2}$. In that case, $\cos(\theta)>0$,
  so $\vec{a}\cdot \vec{b} >0$.
  \item On the other hand, when $\theta $ is an obtuse angle, that means $\frac{\pi}{2}< \theta < \pi$.
  In that case, $\cos(\theta)<0$, and so $\vec{a}\cdot \vec{b} <0$.
  \item When we have a right angle, $\theta=\frac{\pi}{2}$, so in that case $\vec{a}\cdot \vec{b} =0$. 
\end{itemize}

\subsection{Projection}
\begin{definition}[Vector Projection]
  \label{def:vector-projection}
  Let $\vec{a},\vec{b}$ be vectors. The \demph{vector projection of $\vec{b}$ onto $\vec{a}$} is
  \begin{align*}
    \vec{P}
    &:= \left( \frac{\vec{a}\cdot \vec{b}}{|\vec{a}|} \right) \left(\frac{\vec{a}}{|\vec{a}|}\right)\\
    &= \left( \text{length of }P \right)\left( \text{unit vector} \right) \nonumber
  \end{align*}
  The book uses the notation $\vec{P} = \text{proj}_{\vec{a}}(\vec{b})$.
\end{definition}

To break this equation down, observe that $\frac{\vec{a}}{|\vec{a}|}$ is a unit vector in the direction
of $\vec{a}$. The quantity in parentheses is a number, not a vector. It scales the unit vector
$\frac{\vec{a}}{|\vec{a}|}$. This number is the (signed) length of the shadow cast by $\vec{b}$ on
$\vec{a}$ when the sun is directly overhead. It is called the \demph{component of $\vec{b}$ along
  $\vec{a}$}, or alternatively, the \demph{scalar projection of $\vec{b}$ onto $\vec{a}$}.

I think of projections in terms of shadows.


\Fl{Question:}  Why is $\frac{\vec{a}\cdot \vec{b}}{|\vec{a}|}$ equal to the (signed) length of $\vec{P}$?

 
\fl{Answer:} Suppose we've got two vectors like this:
\begin{center}
  \begin{tikzpicture}
    % Draw vectors
    \draw[->, thick] (0,0) -- (3,2) node[above] { $\vec{b}$} ;%
    \draw[->, thick] (0,0) -- (4,0) node[right] { $\vec{a} $ };%

    % Label angle
    \draw (1.2,0) arc[start angle=0, end angle=33.69, radius=1.2cm];%
    \node at (1.5,0.4) {$\theta$};%
  \end{tikzpicture}
\end{center}


Now let's draw the projection $\vec{P}$, along with a dotted line perpendicular to $\vec{a}$:

\begin{center}
  \begin{tikzpicture}
    % Draw vectors
    \draw[->, thick] (0,0) -- (3,2) node[above] { $\vec{b} $ };%
    \draw[->, thick] (0,0) -- (4,0) node[right] { $\vec{a}$ };%
    \draw[->, very thick, red] (0,0) -- (3,0) node[below] { $\vec{P}$ };%
    \draw[dotted] (3,0) -- (3,2) ;%
    % Label angle
    \draw (1.2,0) arc[start angle=0, end angle=33.69, radius=1.2cm];%
    \node at (1.5,0.4) {$\theta$};%
  \end{tikzpicture}
\end{center}
Note that we have a right angle. By trigonometry, we know that
\begin{equation*}
  \cos(\theta) = \frac{\text{length of adjacent side}}{\text{length of hypotenuse}}
\end{equation*}
In our case, that means
\begin{equation}
  \label{eq:4}
  \cos(\theta) = \frac{\text{length of }\vec{P}}{\text{length of }\vec{b}} = \frac{|\vec{P}|}{|\vec{b}|}
\end{equation}
ON THE OTHER HAND, by \cref{thm:dot-productangle-relationship}, we ALSO know that
\begin{equation}
  \label{eq:5}
  \cos(\theta) = \frac{\vec{a}\cdot \vec{b}}{|\vec{a}||\vec{b}|}
\end{equation}
Therefore, combining \cref{eq:4,eq:5}, we have:
\begin{equation*}
  \frac{|\vec{P}|}{|\vec{b}|} =  \frac{\vec{a}\cdot \vec{b}}{|\vec{a}||\vec{b}|},
\end{equation*}
which simplifies to
\begin{equation*}
  \boxed{|\vec{P}| =  \frac{\vec{a}\cdot \vec{b}}{|\vec{a}|}}
\end{equation*}
This answers our original question. [To be pedantic, here we have actually only considered the case where
$\theta$ is an acute angle. The case where $\theta$ is an obtuse angle is a little bit different, but not
much.]



\begin{example}
  A plane is flying in the direction $\vec{D}=\left\langle 1,1 \right\rangle $. The plane is getting hit

  \begin{equation*}

  \end{equation*}

    \text{vector } P 
    &=  |P|   \left( \frac{D}{|D|} \right) \\
    &= \left( \frac{100}{\sqrt{2}} \right) \left(\frac{ \left\langle 1,1 \right\rangle}{\sqrt{2}}  \right) \\
    &=\left\langle 50,50 \right\rangle 
  \end{align*}
\end{example}

\begin{definition}[Vector Projection]
  \label{def:vector-projection}
  Let $A,B$ be vectors. The \demph{vector projection of $B$ along $A$} is
  \begin{align*}
    {P}
    &:= \left( \frac{A\cdot B}{|A|} \right) \left(\frac{A}{|A|}\right)\\
    &= \left( \text{signed length of }P \right)\left( \text{unit vector} \right) \nonumber
  \end{align*}
  The book uses the notation ${P} = \text{proj}_{A}(B)$, and
  $\text{comp}_{A}B= \frac{A\cdot B}{|A|}$
\end{definition}


\begin{example}
  Find the vector projection of $\vec{b}=\left\langle 1,1,2 \right\rangle $ onto
  $\vec{a} = \left\langle -2,3,1 \right\rangle$. 

  \noindent\textit{Solution:} We will first compute the length of $P$:

  \begin{align*}
    \text{signed length of }\overrightarrow{P}
    &= \frac{\vec{a}\cdot \vec{b}}{|\vec{a}|} \\
    &= \frac{(-2)(1)+3(1)+1(2)}{\sqrt{(-2)^{2}+3^{2}+1^{2}}} \\
    &= \frac{3}{\sqrt{14}}
  \end{align*}
  Therefore the length of the projection is $\frac{3}{14}$. Note that we computed $|a|=\sqrt{14}$.

  The vector projection is therefore
  \begin{align*}
    P
    &= \left( \frac{3}{\sqrt{14}} \right) \frac{\vec{a}}{|\vec{a}|}\\
    &= \left( \frac{3}{\sqrt{14}} \right) \frac{\vec{a}}{\sqrt{14}}\\
    &= \frac{3}{14}\vec{a}\\
    &= \frac{3}{14} \left\langle -2, 3,1 \right\rangle \\
    &= \left\langle -\frac{6}{14}, \frac{9}{14}, \frac{3}{14} \right\rangle.

\subsection{Connection to physics: Effective force in a direction}

If a force $\overrightarrow{F}$ is applied to a particle moving along a path, we may wish to know the
magnitude of the force in the direction of motion. If $A$ is a direction, then the projection  of $F$
along $A$ is the \demph{effective force} in the direction $A$.

\begin{example}
  Suppose you are talking a dog on a walk and that you are facing in direction $\overrightarrow{A}$. Suppose the dog
  lunges in some other direction. Let $\overrightarrow{D}$ be force exerted by the pull of the leash.
  Then the effective force with whic the dog pulls you forward is the projection of $D$ along $A$.
  \begin{center}
    \includegraphics[scale=.04]{images/dog-pull}
  \end{center}
  For example, if $A = \left\{1,1,0\right\}$ and $D=\left\langle 13,12,-5 \right\rangle$, then the
  projection is
  \begin{align*}
    P 
    &= \left( \frac{A\cdot D}{|A|} \right) \left( \frac{A}{|A|} \right)\\
    &= \left( \frac{\left\langle 13+12+0 \right\rangle}{\sqrt{2}}  \right)\left( \frac{\left\langle 1,1,0 \right\rangle }{\sqrt{2}} \right)\\   
    &= \left( \frac{25}{\sqrt{2}} \right) \left\langle \frac{1}{\sqrt{2}},\frac{1}{\sqrt{2}},0 \right\rangle\\ 
    &= \left\langle \frac{25}{2},\frac{25}{2},0 \right\rangle .
  \end{align*}
  The length of $P$ is
  \begin{equation*}
    |P| = \frac{A\cdot D}{|A|} = \frac{25}{\sqrt{2}}\approx 17.7.
  \end{equation*}
  So the dog pulls you forward with about $17.7\ \mathrm{N}$ of force. That's not enough to topple you
  unless you are either very frail, or a toddler.
\end{example}

\begin{example}

    |A| = \sqrt{(-4)^{2}+(-1)^{2}} = \sqrt{17},

\subsection{Cross Product}

The idea of ``slope'' allows us to describe the tilt of a line. We need something analogous for
describing the tilt of a plane. This is done with by describing a vector that is \textit{perpendicular}
to the plane, called the \demph{normal vector}. So we need a way to find vectors that are perpendicular
to things. In 3D, the simplest way to do this is with the following operation (it's not really simple,
sorry):

\begin{definition}[Cross Product]
  \label{def:cross-product}
  Let $\vec{a}=\left\langle a_{1},a_{2},a_{3} \right\rangle $ and $\vec{b} = \left\langle b_{1},b_{2},b_{3}
  \right\rangle$. The \demph{cross product} of $\vec{a}$ and $\vec{b}$, denoted $\vec{a}\times \vec{b}$ is the vector
  \begin{equation*}
    \vec{a} \times \vec{b} = \left\langle a_{2}b_{3}-a_{3}b_{2},\ \ a_{3}b_{1}-a_{1}b_{3},\ \ a_{1}b_{2}-a_{2}b_{1}\right\rangle.
  \end{equation*}
\end{definition}
\fl{Fact 1:} This new vector is orthogonal to both $\vec{a}$ and $\vec{b}$.

\fl{Fact 2:} There is no cross product for 2D.

There is a trick to computing cross products, and remembering how to compute
them. This is called the \demph{method of cofactor expansion}, which I will
demonstrate now. This method touches on important ideas that arise in linear
algebra, which gives it additional value in its own right. Given a two-by two matrix
\begin{equation*}
  \begin{bmatrix}
    a&b\\
    c&d
  \end{bmatrix}
\end{equation*}
the determinant of the matrix, which we denote by  $\begin{vmatrix} a&b\\c&d \end{vmatrix}$, is the quantity
\begin{equation*}
  \begin{vmatrix}
    a&b\\
    c&d
  \end{vmatrix}
  = ad-bc.
\end{equation*}
The cross product $\vec{a}\times \vec{b}$ can be computed as
\begin{equation*}
  \begin{vmatrix}
    \vec{\imath}&\vec{\jmath}&\vec{k}\\
    a_{1}&a_{2}&a_{3}\\
    b_{1}&b_{2}&b_{3}\\
  \end{vmatrix}
  =
  \vec{\imath}
  \begin{vmatrix}
    a_{2}&a_{3}\\
    b_{2}&b_{3}\\
  \end{vmatrix}
  -
  \vec{\jmath}
  \begin{vmatrix}
    a_{1}&a_{3}\\
    b_{1}&b_{3}\\
  \end{vmatrix}
  +
  \vec{k}
  \begin{vmatrix}
    a_{1}&a_{2}\\
    b_{1}&b_{2}\\
  \end{vmatrix}
\end{equation*}
Note that the sign \textit{alternates:} the term with the $\vec{\jmath}$ is subtracted, not
added like the first and third term.
\begin{example}
  Suppose $\vec{a} = \left\langle 1,3,4 \right\rangle $ and $\vec{b} = \left\langle 2,7,-5 \right\rangle$.
  The cross product is
  \begin{align*} 
    \begin{vmatrix}
      \vec{\imath}&\vec{\jmath}&\vec{k}\\
      1&3&4\\
      2&7&-5\\
    \end{vmatrix}
    &=
    \vec{\imath}
    \begin{vmatrix}
      3&4\\
      7&-5\\
    \end{vmatrix}
    -
    \vec{\jmath}
    \begin{vmatrix}
      1&4\\
      2&-5\\
    \end{vmatrix}
    +
    \vec{k}
    \begin{vmatrix}
      1&3\\
      2&7\\
    \end{vmatrix}\\
    &=\vec{\imath} \left(-15-28  \right) - \vec{\jmath}\left( -5-8 \right) +\vec{k}\left( 7-6 \right)\\
    &=\vec{\imath} \left(-43  \right) - \vec{\jmath}\left( -13 \right) +\vec{k}\left(1 \right)\\
    &=\left\langle -43,13,1 \right\rangle 
  \end{align*}
  \textbf{Check our answer:} Is this new vector indeed orthogonal to both
  $\vec{a}$ and $\vec{b}?$ To check this, we can use the fact that two vectors $A$ and $B$ are orthogonal precisely
  when $A\cdot B=0$. Indeed, doing the dot product computation gives
  \begin{equation*}
    \vec{a} \cdot \left\langle -43,13,1
    \right\rangle= \left\langle 1,3,4  \right\rangle \cdot \left\langle -43,13,1
    \right\rangle= -43+39+4 = 0
  \end{equation*}
  Since this dot product is zero, we conclude that our new vector $\vec{a}\times \vec{b}$ is orthogonal to $\vec{a}$.
  Similarly, we have
  \begin{equation*}
    \vec{b}\cdot \left\langle -43,13,1 \right\rangle= \left\langle 2,7,-5 \right\rangle\cdot \left\langle -43,13,1
    \right\rangle= -86+91-5 =0,
  \end{equation*}
  and this implies that $\vec{a}\times \vec{b}$ is orthogonal to $\vec{b}$.
\end{example}
\newpage
The next theorem establishes a geometric interpretation of the cross product:
\begin{theorem}
  Let $\vec{u}$ and $\vec{v}$ be 3d vectors. If $\vec{u}$ and $\vec{v}$ are not
  parallel, then the vectors determine a plane. The plane is
  \begin{equation*}
    P = \left\{(x,y,z)\in \R^{3} :
      (x,y,z) = c_{1} \vec{u}+ c_{2} \vec{v} \text{ for some } c_{1},c_{2}\in R^{2}\right\}
  \end{equation*}
  In words, $P$ is set of all \demph{linear combinations} of the vectors
  $\vec{u}$ and $\vec{v}$. We select a unit vector $\vec{n}$ called the \demph{unit
    normal vector} according to the right hand rule as follows.
  \begin{center}
    \includegraphics[scale=.6]{images/right-hand-rule}
  \end{center}
  In words, if your fingers curl from $\vec{u}$ to $\vec{v}$, then $\vec{n}$
  points in the direction of your thumb. Then
  \begin{equation}\label{eq:geometric-interp-of-cross-product}
    \vec{u}\times \vec{v} = \left( |\vec{u}| |\vec{v}| \sin(\theta) \right)\vec{n}.
  \end{equation}
  where $\theta\in [0,\pi]$ is the angle between the two vectors $\vec{u}$ and $\vec{v}$.
\end{theorem}

This geometric interpretation comes with a number of implications:
\begin{enumerate}[(A)]
  \item \cref{eq:geometric-interp-of-cross-product} implies that two vectors $\vec{u}$
  and $\vec{v}$ are parallel (i.e., so that $\theta=0$), precisely when
  \begin{equation*}
    \vec{u}\times \vec{v} = 0.
  \end{equation*}
  \item We verify the fact, stated earlier, that $\vec{u}\times \vec{v}$ is
  orthogonal to both $\vec{u}$ and $\vec{v}$.
  \item The cross product is \textit{anticommutative}:
  \begin{equation*}
    \vec{v}\times \vec{u} = -(\vec{u}\times \vec{v})
  \end{equation*}
  Because when computing $\vec{v}\times \vec{u}$, your fingers have to sweep from $\vec{v}$ to $\vec{u}$,
  which causes your thumb to point the other way, as shown:
  \begin{center}
    \includegraphics[scale=.6]{images/right-hand-rule-upside-down}
  \end{center}
  And geometrically, reversing the direction of vector is the same as mupltiplying it by $-1$. This is is
  why
  \begin{equation*}
    \vec{v}\times \vec{u} = -(\vec{u}\times \vec{v})
  \end{equation*}
\end{enumerate}

\begin{example}[Application to physics: torque]
  Suppose we have a wrench, whose handle is represented by a vector $\vec{r}$. Turning the wrench will
  tighten a bolt or something. The tendency of an object to rotate is represented by a vector called
  the \demph{torque vector}, denoted $\vec{\tau}$, which is similar to---but \textit{not} the same as---a force vector.

 The magnitude of $\tau$, $|\tau|$ determines how much push there is to
  rotate:
  \begin{equation*}
    \text{bigger }|\tau| = \text{more push to rotate}
  \end{equation*}
  This is similar to a force vector. What is different is that for a force vector $\vec{F}$, the
  direction of $\vec{F} $ indicates the direction in which motion would occur. This is NOT the case for
  torque. For torque, as we will see, the direction instead indicates the following two things:
  \begin{itemize}
    \item the axis of rotation
    \item whether the rotation is clockwise or anticlockwise.
  \end{itemize}
  Suppose that the bolt is stuck, so I take a hammer and hit the end of my wrench.
  The hammer strike is represented by a force vector $F$, as shown:

  \begin{center}
    \includegraphics[scale=0.05]{images/torque-wrench}
  \end{center}
  Notice that I didn't have great aim, so although my hammer hit the tip of the wrench, the hammer didn't
  come down exactly perpendicular to the wrench. Instead, it was at a bit of an angle $\theta$.

  The direction of $\tau$ is always parallel to the axis of rotation---so $\tau$ will be a vector which
  passes through the bolt. Whether it points up or down is always determined by whether the rotation is
  clockwise or anticlockwise, according to the right-hand rule.
  \footnote{i.e., if you curl the fingers of your right hand along the axis in the direction of the
    rotation, then $\tau$ should point in the direction of your thumb. Whether $\tau$ points up or down
    has nothing to do with whether the bolt gets looser or tighter.. the direction only indicates whether
    the rotation is clockwise or anticlockwise.}

  In this setting, if we think about this phsically, we will conclude that the magnitude of the torque
  should be determined by two things:
  \begin{itemize}
    \item The length of the wrench handle $|\vec{r}|$. 
    \item How much of the force gets applied in the direction perpendicular to $\vec{r}$. In the picture
    above, this is the magnitude of the vector $\vec{c}$. The vector $\vec{c}$ is the component of
    $\vec{F}$ which is perpendicular to $\vec{r}$.  In particular we can compute $|\vec{c}|$ by observing that
    \begin{equation*}
      \sin(\theta) = \frac{\text{opposite}}{\text{hypotenuse}}\frac{|\vec{c}|}{|\vec{F}|}
    \end{equation*}
    so that
    \begin{equation*}
      |\vec{c}| = |\vec{F}|\sin(\theta).
    \end{equation*}
  \end{itemize}
  It turns out that the cross product is the right thing to use to represent the torque. That is, we
  define
  \begin{equation*}
    \vec{\tau} = \vec{r}\times \vec{F}
  \end{equation*}
  In particular, by \cref{eq:geometric-interp-of-cross-product}, the magnitude of the torque is
  \begin{align*}
    |\vec{\tau}| 
    &=|\vec{r}\times \vec{F}|\\
    &=\underbrace{|r|}_{\overset{\text{length of}}{\text{wrench}}} \underbrace{|F| \sin(\theta)}_{|\vec{c}|}
  \end{align*}

\end{example}

  &= |\vec{r}\times \vec{F}|\\
  &=|r| |F| \sin(\theta)\\

  &\approx 9.66 \mathtt{Nm}\\
  &=9.66 \mathtt{J}
\end{align*}

\begin{equation*}
  \tau\approx  9.66 \vec{n}
\end{equation*}
What direction does $\vec{n}$ point? If we are tightening the bolt then the
rotation is clockwise, and the torque vector points away from us. (This matches
with the righty-tighty lefty-loosy convention that almost all bolts and screws
obey.)



\subsection{Lines in any dimension}
\textit{12.5 in Stewart}


In this section, we'll use the notation $\R^{n}$ to mean $n$-dimensional space,
which is the set of points of the form
\begin{equation*}
  (x_{1},x_{2},\ldots,x_{n})
\end{equation*}
where $x_{1},\ldots,x_{n}$ are all real numbers. You are already familiar with
$\R^{2}$ and $\R^{3}$, where we usually use $(x,y)$ or $(x,y,z)$ rather than
$(x_{1},x_{2})$ or $(x_{1},x_{2},x_{3})$.

Let $\vec{v}=(v_{1},\ldots,v_{n})$ is a nonzero vector in $n$-dimensional space.
You can think of $n=2$ or $n=3$, but what follows will hold for any positive
integer $n$. Then for any scalar $t$, the vector $t\vec{v}$ has the same
direction as $v$ when $t>0$ and opposite direction when $t<0$. Therefore the set
of points
\begin{equation*}
  \left\{t\vec{v}: -\infty<t<\infty\right\}
\end{equation*}
is a line through the origin. We we add a vector $\vec{p}=\left\langle
  x_{0},y_{0},z_{0} \right\rangle $ to all of those points, we obtain
\begin{equation*}
  \left\{t\vec{v}+ \vec{p}: -\infty<t<\infty\right\}
\end{equation*}
which is a line through $\vec{p}$ in the direction of $\vec{v}$. 

\begin{definition}[vector equation of a line]
  \label{def:vector-equation-line}
  Given a vector $\vec{p}$ and a nonzero vector $\vec{v}$ in $\R^{n}$, the set
  of all points $\vec{y}$ in $\R^{n}$ such that
  \begin{equation}\label{eq:vector-equation-of-a-line}
    \vec{y}=t \vec{v} + \vec{p}
  \end{equation}
  where $-\infty<t<\infty$ is called the \demph{line through $\vec{p}$ in the
    direction of $\vec{v}$}.
\end{definition}
If we write $\vec{y}=(y_{1},y_{2},\ldots,y_{n})$ and
$\vec{v}=(v_{1},v_{2},\ldots,v_{n})$ and $\vec{p}=(p_{1},p_{2},\ldots,p_{n})$,
then \cref{eq:vector-equation-of-a-line} can be written as
\begin{equation*}
  \begin{bmatrix}
    y_{1}\\y_{2}\\\vdots\\y_{n}
  \end{bmatrix}
  =
  t
  \begin{bmatrix}
    v_{1}\\v_{2}\\\vdots\\v_{n}
  \end{bmatrix}
  +
  \begin{bmatrix}
    p_{1}\\p_{2}\\\vdots\\p_{n}
  \end{bmatrix}
\end{equation*}
This vector equation can be written as
\begin{equation*}
  \left\{ \begin{array}{l@{}l}
      y_{1}=v_{1}t+p_{1}\\
      y_{2}=v_{2}t+p_{2}\\
      \vdots\\
      y_{n}=v_{n}t+p_{n}\\
      -\infty<t<\infty
    \end{array}\right.
\end{equation*}
which are called the \demph{parametric equations of a line.}

\begin{example}
  Suppose $L$ is the line in $\R^{2}$ through the point $\vec{p}=(1,2)$ in the
  direction of $\vec{v}=(1,-3)$. Then the vector equation of the line is
  \begin{equation*}
    \vec{y} 
    = t \left\langle 1,-3 \right\rangle +(1,3) 
    = \left\langle t+1,-3t+2 \right\rangle 
  \end{equation*}
  for $-\infty<t<\infty$. If we let $\vec{y}=\left\langle x,y \right\rangle$,
  this is the parametric equations
  \begin{equation*}
    \left\{ \begin{array}{l@{}l}
        x=t+1 \\
        y=-3t+2. \\
      \end{array}\right.
  \end{equation*}
  If we eliminate $t$, we get the equation
  \begin{equation*}
    y=-3x+5.
  \end{equation*}
\end{example}

\begin{example}
  Consider the following two points in 3D space
  \begin{equation*}
    A = (2,4,-3) \quad \text{and} \quad B = (3,-1,1)
  \end{equation*}
  \begin{enumerate}[(a)]
    \item Find the equation of the line which passes through $A$ and $B$
    \item Find the equation of the line segment which connects $A$ and $B$.
  \end{enumerate}

  \textit{Solution to (a):}
  We will follow the ideas presented in \cref{def:vector-equation-line}. Let $\vec{v} = \overrightarrow{AB} = \left\langle 1,-5,4 \right\rangle$. We
  need a vector $\vec{p}$ on the line, so we can take either $\vec{p}=A$ or
  $\vec{p}=B$ since both of these points is on the line. Let's take $\vec{p}=A$.
  Then the vector equation of the line is
  \begin{equation*}
    \left\langle y_{1},y_{2},y_{3} \right\rangle 
    = t\left\langle 1,-5,4 \right\rangle +\left\langle 2,4,-3 \right\rangle 
  \end{equation*}
  and the parameteric equations of the line are
  \begin{equation*}
    \left\{ \begin{array}{l@{}l}
        y_{1}=t+2\\
        y_{2}=-5t+4\\
        y_{3}=4t-3 \\
        -\infty<t<\infty
      \end{array}\right.
  \end{equation*}

  Since we are working in 3 dimensions, we may wish to write $x,y,z$ rather than
  $y_{1},y_{2},y_{3}$, in which case our equations become
  \begin{equation*}
    \left\langle x,y,z \right\rangle
    =t \left\langle 1,-5,4 \right\rangle + \left\langle 2,4,-3 \right\rangle
  \end{equation*}
  and
  \begin{equation*}
    \left\{ \begin{array}{l@{}l}
        x=t+2\\
        y=-5t+4\\
        z=4t-3 \\
        -\infty<t<\infty
      \end{array}\right.
  \end{equation*}

  \textit{Solution to (b):} Since $\overrightarrow{AB}=(B-A)$, observe that our
  equation is of the form
  \begin{equation*}
    \left\langle x,y,z \right\rangle  = \overrightarrow{AB}t+A
  \end{equation*}
  or
  \begin{equation*}
    \left\langle x,y,z \right\rangle  = (B-A)t+A
  \end{equation*}
  When $t=0$, we have
  \begin{equation*}
    \left\langle x,y,z \right\rangle =A.
  \end{equation*}
  In other wordss, when $t=0$, the ant is at point $A$. As $t$ increases, the
  ant walks in the direction $\overrightarrow{AB}$, i.e., towards $B$.

  Moreover, when $t=1$, we have
  \begin{equation*}
    \left\langle x,y,z \right\rangle= (B-A)(1)+A = B.
  \end{equation*}
  so the ant arrives at point $B$ at time $t=1$.
  So the equation of the line segement between $A$ and $B$ is
  \begin{equation*}
    \left\{ \begin{array}{l@{}l}
        \left\langle x,y,z \right\rangle
        = t \left\langle 1,-5,4 \right\rangle
        + \left\langle 2,4,-3 \right\rangle  \\
        0 \leq t \leq 1
      \end{array}\right.
  \end{equation*}

  This example also illustrates the more general fact that the \demph{line
    segment} between two points $A$ and $B$ is given by the parametric equation
  \begin{align*}
    \left\langle x,y,z \right\rangle 
    &= (B-A)t+A\\
    &= tB+(1-t)A
  \end{align*}
  for $0 \leq t \leq 1$.

  (This equation makes sense: e.g. if $t=1/2$ then we get the midpoint between
  $A$ and $B$.)
\end{example}

\subsection{Planes in 3D}

In the last lecture we saw that a \demph{line} in $n$-dimensional space can be represented as the set of points
$\vec{y}=(y_{1},\ldots,y_{n})$ such that
\begin{equation*}
  \left\{ \begin{array}{l@{}l} \vec{y}=t \vec{v}+\vec{p} \\
      -\infty<t<\infty  \end{array}\right.
\end{equation*}
where $\vec{v}=\left\langle v_{1},\ldots,v_{n} \right\rangle $ is a nonzero vector and
$\vec{p}=\left\langle p_{1},\ldots,p_{n} \right\rangle $ represents any point in $n$-dimensional space.


If we have another nonzero vector $\vec{u}$ which isn't parallel to $\vec{v}$, then the set of points
$\vec{y}$ satisfying the equation
\begin{equation}\label{eq:definition-of-parametric-form-eq-of-plane}
  \left\{ \begin{array}{l@{}l} \vec{y}=t \vec{v}+ s\vec{u}+\vec{p} \\
      -\infty<s,t<\infty \end{array}\right.
\end{equation}
is a \demph{plane}. This is called the parametric equation of a plane.

We'll focus on understanding planes in 3-dimensional space. A plane $\P$ in 3D space is uniquely
determined by the following two things:
\begin{itemize}
  \item A normal vector $\vec{n} = (A,B,C)$, which determines the tilt of the
  plane (Note: $A,B,C$ are real numbers)
  \item A point $\vec{p}=(x_{0},y_{0},z_{0})$ which the plane passes through, to
  determined the location in 3D space where the plane lies.
\end{itemize}
The plane $\P$ consists of the set of points $(x,y,z)$ satisfying the following
equation:
\begin{equation}\label{eq:definition-normal-form-eq-of-plane}
  A(x-x_{0}) + B(y-y_{0})+C(z-z_{0})=0
\end{equation}
\cref{eq:definition-normal-form-eq-of-plane} is called the \demph{normal form} equation of the plane.
Frequently this is written as
\begin{equation*}
  Ax+By+Cz=D
\end{equation*}
where $D = Ax_{0}+By_{0}+Cz_{0}$.

We can also write \cref{eq:definition-normal-form-eq-of-plane} as the following dot product:
\begin{equation*}
  \underbrace{\left\langle A,B,C \right\rangle}_{\text{this is }\vec{n}} \cdot \left\langle x-x_{0},y-y_{0},z-z_{0} \right\rangle  =0
\end{equation*}
or
\begin{equation*}
  \vec{n}\cdot
  \begin{bmatrix}
    x-x_{0}\\y-y_{0}\\z-z_{0}
  \end{bmatrix}
  =0
\end{equation*}

\begin{example}
  Find the normal equation of the plane through the point $\vec{p} = (2,4,-1)$ with
  normal vector $\vec{n}=\left\langle 2,3,4 \right\rangle$. Find the intercepts
  and sketch the plane.

  \textit{Solution:} By \cref{eq:definition-normal-form-eq-of-plane}, with $A=2$, $B=3$, $C=4$, we have:
  \begin{equation*}
    2(x-2)+3(y-4)+4(z+1)=0.
  \end{equation*}
  We are done. We could also write this as:
  \begin{equation}\label{eq:7}
    2x+3y+4z=12.
  \end{equation}
  To find the intercepts, we consider what happens when we set two of the variables $x,y,z$ equal to zero
  at a time:
  \begin{itemize}
    \item To find the $x$-interecept, set $y=z=0$ in \cref{eq:7}. In that case, we get $x=6$. Hence
    the $x$-intercept is $(6,0,0)$.
    \item To find the $y$-interecept, set $x=z=0$ in \cref{eq:7}. In that case, we get $y=4$. Hence
    the $y$-intercept is $(0,4,0)$.
    \item To find the $z$-interecept, set $x=y=0$ in \cref{eq:7}. In that case, we get $z=3$. Hence
    the $z$-intercept is $(0,0,3)$.
  \end{itemize}

\subsection{Cylinders and quadric surfaces}
Let $f=f(x,y,z)$ be a function. A \demph{level set} of $f$ is an set of the from
\begin{equation*}
  \left\{(x,y,z)\in \R^{3} : f(x,y,z)=c\right\}
\end{equation*}
where $c\in \R$.

If we take $c=0$,
\begin{equation*}
  \left\langle (x,y,z)\in \R^{3}: f(x,y,z)=0  \right\rangle 
\end{equation*}
is called the \demph{zero set} of $f$. For brevity, we usually don't write out all the set notation, and instead
just write the equation, like this:
\begin{equation*}
  f(x,y,z)=0.
\end{equation*}
Frequently, level sets form interesting shapes or surfaces, especially in higher dimensions. In two
dimensions,
\begin{itemize}
  \item $y-x^{2}=0$ is a parabola
  \item $2x+y-3=0$ is a line
  \item $x^{2}+y^{2}=0$ is a circle
\end{itemize}
Here we focus on 3-dimension. Here are some examples in 3-dimensions
\begin{itemize}
  \item $x^{2}+y^{2}-1=0$ is the unit cylinder
  \item $x^{2}+y^{2}+z^{2}-9=0$ is a sphere with radius 3.
  \item $z=x^{2}$ is a parabolic cylinder
  \item $Ax+By+Cz+D=0$ is a plane
\end{itemize}

In 3-dimensions, a \demph{quadric surface} is the zero set of a degree 2 polynomial in the variables
$x,y,$ and $z$. In other words, it is the graph of an equation of the form
\begin{equation*}
  Ax^{2}+By^{2}+Cz^{2}+Dxy+Eyz+Fxz+Gx+Hy+Iz+J = 0,
\end{equation*}
wher $A,B,\ldots,J$ are real numbers. This forms a surface. There are, obviously, lots of possibilities
so we can't do them all, but we'll do some special cases that will provide a rich source of examples of
surfaces in 3D that we can work with.

Before we start we recall some things from 2-dimensional space (see section 10.5 in the texbook):

\begin{proposition}[Conic sections in 2D]
  \label{prop:conic-sections-2d}
  \begin{enumerate}
    \item[]
    \item The equations
    \begin{equation*}
      \frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}} =1 
    \end{equation*}
    is an ellipse passing through the points  $(a,b), (a,-b), (-a,b)$ and $(-a,-b).$
    \item  The equation
    \begin{equation*}
      \frac{x^{2}}{a^{2}}-\frac{y^{2}}{b^{2}}=1
    \end{equation*}
    is a hyperbola which opens to the sides with vertices $(\pm a,0)$ and asymptotes $y=\pm\frac{b}{a}x$.
    \item The equation
    \begin{equation*}
      \frac{y^{2}}{a^{2}}-\frac{x^{2}}{b^{2}}=1
    \end{equation*}
    is a hyperbola which opens up and down, with vertices $(0,\pm b)$ and asymptotes $y=\pm \frac{a}{b}x$
  \end{enumerate}
\end{proposition}


\begin{example}[Quadric Form, Special case \#1: Ellipsoid]
  \label{ex:quadric-form-special-case-1}
  Consider the quadric form 
  \begin{equation*}
    \frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}+\frac{z^{2}}{c^{2}}-1=0.
  \end{equation*}
  For example,
  \begin{equation*}
    x^{2}+\frac{y^{2}}{9}+\frac{z^{2}}{4}-1=0
  \end{equation*}
  What is this shape?

  To help determine, we will consider the \demph{traces}, which are the cross-sections of the surface
  obtained by intersecting it with planes parallel to the coordinate planes.

  For example, we could intersect the surface with the plane $z=k$, where $k$ is a number. This plane is
  parallel to the $xy$-plane. That gives
  \begin{equation*}
    x^{2} + \frac{y^{2}}{9}+ \frac{k^{2}}{4}-1=0
  \end{equation*}
  or
  \begin{equation*}
    x^{2}+\frac{y^{2}}{9}=1-\frac{k^{2}}{4}.
  \end{equation*}
  As long as $k^{2}<4$, we can write this as
  \begin{equation*}
    \frac{x^{2}}{1-\frac{k^{2}}{4}} + \frac{y^{2}}{9(1-\frac{k^{2}}{4})} = 1
  \end{equation*}
  which is the equation of an ellipse by \cref{prop:conic-sections-2d}.

  All of the traces are ellipses. (You should check this). Ths is an \demph{ellipsoid}.
\end{example}

\subsection{Vector functions and space curves}
\textit{Please read sections 13.1 and 13.2}

We are interested in describing \textbf{motion along a curve}.


A \demph{vector-valued} function is a function whose domain is a set of real numbers and whose range is a
set of vectors. We are most interested in the 3-dimensional case:
\begin{equation*}
  \vec{r}(t) = \left\langle f(t),g(t),h(t) \right\rangle =
  \begin{bmatrix}
    f(t)\\g(t)\\h(t)
  \end{bmatrix}
\end{equation*}

We've already seen these, for lines. Recall that if $\vec{v}$ is any nonzero vector, and
$\vec{p}=(x_{0},y_{0},z_{0})$ is a point, then 
\begin{equation*}
  \vec{r}(t) = \vec{v}t + \vec{p}
\end{equation*}
describes the motion of a particle along a line (in the direction of $\vec{v}$, through the point
$\vec{p}$). For example
\begin{equation}\label{eq:6}
  \vec{r}(t) = \left\langle 1,-5,4 \right\rangle t + \left\langle 2,4,-3 \right\rangle 
\end{equation}

We define the \demph{limit} of such a function in the following way:
\begin{equation*}
  \lim_{t \to a} \vec{r}(t) =
  \begin{bmatrix}
    \lim_{t \to a} f(t)\\
    \lim_{t \to a} g(t)\\
    \lim_{t \to a} h(t)
  \end{bmatrix}
\end{equation*}

For example if 
\begin{equation*}
  \vec{r}(t) =
  \begin{bmatrix}
    2+t^{3}\\
    \frac{\sin(t)}{t}\\
    t e^{-t}
  \end{bmatrix}
\end{equation*}
then
\begin{equation*}
  \lim_{t\to 0}\vec{r}(t)  =
  \begin{bmatrix}
    2\\1\\0
  \end{bmatrix}
\end{equation*}
Let $a$ be a real number. A  vector-valued function $\vec{r}$ is said to be \demph{continuous at $a$} if
\begin{equation*}
  \lim_{t \to a} \vec{r}(t) = \vec{r}(a)
\end{equation*}
In other words, when the component function $f,g,$ and $h$ are all continuous.

Vector valued functions define curves through space. The curve is the set of points satisfying the
parametric equation
\begin{equation*}
  \left\{ \begin{array}{l@{}l}
      x = f(t) \\
      y = g(t) \\
      z = h(t) 
    \end{array}\right.
\end{equation*}
for all $t$ in the domain of $\vec{r}$.


The \demph{derivative} of a vector-valued function $\vec{r}(t)$ is defined as
\begin{equation*}
  \vec{r}'(t)  = \left\langle f'(t),g'(t),h'(t) \right\rangle 
\end{equation*}
provided that this limit exists.



\textbf{Important:} The derivative of $\vec{r}(t)$ in \cref{eq:6} is $\vec{v}$. The particle moves at a
constant velocity $\vec{v}$.


Observations
\begin{itemize}
  \item $\vec{r}'$ is vector-valued function
  \item for a particular particular value of $t$, the quantity $\vec{r}(t)$ is the \textbf{tangent
    vector} to the curve at the point $\vec{r}(t)$. We will frequently work with the \demph{unit tangent
    vector}, which is 
  \begin{equation*}
    \vec{T}(t) = \frac{\vec{r}'(t)}{|\vec{r}'(t)|}
  \end{equation*}
  \item The unit tangent vector is the derivative, normalized
\end{itemize}



The \demph{definite integral} of a vector function $\vec{r}(t)$ is defined as
\begin{equation*}
  \int_{a}^{b}\vec{r}(t)dt = \left\langle \int_{a}^{b}f(t)dt , \int_{a}^{b}g(t)dt, \int_{a}^{b}h(t)dt    \right\rangle  
\end{equation*}

\begin{example}[Helix]
  \begin{equation*}

  The magnitude of the derivative is
  \begin{equation*}
    |\vec{r}'(t)| = \sqrt{(-\sin t)^{2}+(\cos t)^{2}+1}= \sqrt{2}.
  \end{equation*}
  The unit tangent vector is
  \begin{equation*}
    \vec{T}(t)
    = \frac{\vec{r}'(t)}{|\vec{r}'(t)|}
    = \left\langle -\frac{\sin(t)}{\sqrt{2}}, \frac{\cos(t)}{\sqrt{2}}, \frac{1}{\sqrt{2}} \right\rangle 
  \end{equation*}
  Suppose that the coordinate axes are measured in meters and time is measured in seconds. If
  $\vec{r}(t)$ describes the motion of a particle, then the particle starts at the origin, and travels
  upwards, rotating around the $z$-axis exactly 5 times before coming to a halt after $t=10\pi$ seconds.
  The velocity of the particle at time $t$ seconds is given by $\vec{r}'(t)$. Velocity has two
  components: a magnitude and a direction. The magnitude is known as \demph{speed}. In this case, the
  speed is a constant $\sqrt{2}$ meters per second. The unit tangent vector tells us the direction that
  the particle is headed at a given instant, but tells us nothing about the speed.

  \textbf{Question:} How far did the particle travel? Here, I am asking for arc length. The formula is
  \begin{equation*}
    \text{Arc length} 
    = \int_{a}^{b}\sqrt{\left( \frac{dx}{dt} \right)^{2}
      + \left(\frac{dy}{dt} \right)^{2} + \left(\frac{dz}{dt} \right)^{2}} dt
  \end{equation*}
  This can be written more compactly as
  \begin{equation*}
    \boxed{\text{Arc length} = \int_{a}^{b}|\vec{r}\ '(t)|dt.}
  \end{equation*}
  In our case, $a=0$, $b=10\pi$, and $|r'(t)| = \sqrt{2}$. So
  \begin{equation*}
    \text{Arc length} = \int_{0}^{10\pi}\sqrt{2}dt = 10\pi\cdot \sqrt{2} \approx 44 \text{ meters.}
  \end{equation*}
  The particle traveled $10\pi\cdot \sqrt{2}$ meters. This makes sense: after all, the particle traveled
  at a constant velocity of $\sqrt{2}$ meters per second for $10\pi$ seconds. So of course it traveled
  $10\pi \sqrt{2}$ meters.
\end{example}

More generally the \demph{arc length function} is defined as
\begin{equation*}
  s(t) = \int_{a}^{t}|r'(u)| du,
\end{equation*}
for $t \geq a$, and where $a$ is the starting point of the particle.

In the previous example, we has $a=0$ and $|r'(t)|=\sqrt{2}$ for all $t$. So
\begin{equation*}
  s(t) = \int_{0}^{t}\sqrt{2}du = \sqrt{2} t
\end{equation*}

Recall the \demph{unit tangent vector} of a parametrized curve $\vec{r}(t)$ is the vector
\begin{equation*}
  \vec{T}(t) = \frac{\vec{r}'(t)}{|\vec{r}\ '(t)|}
\end{equation*}
It's what you get when you normalize the velocity. 

The \textbf{curvature} of a curve at a point is a nonnegative number which measures how quickly the the curve
changes direction at that point. Essentially, it works like this
\begin{itemize}
  \item straight line = zero curvature
  \item wide turns = low curvature
  \item sharp turns = high curvature
\end{itemize}
The direction is given by $\vec{T}(t)$. When a curve is fairly straight, $\vec{T}(t)$ shouldn't change
much over time. But it should change direction quickly when the curve bends or twists sharply.

To be precise, we define \demph{curvature} to be
\begin{equation*}
  \kappa = \left| \frac{d\vec{T}}{ds} \right|
\end{equation*}
where $T$ is the unit tangent vector, and $s$ is the arc length function.

By the chain rule,
\begin{equation*}
  \frac{d\vec{T}}{dt} = \frac{d\vec{T}}{ds} \frac{ds}{dt}
\end{equation*}
or on other words
\begin{equation*}
  T'(t) = \frac{d\vec{T}}{ds}s'(t).
\end{equation*}
Rearranging this, we get:
\begin{equation*}
  \frac{d\vec{T}}{ds} = \frac{1}{s'(t)} T'(t)
\end{equation*}
Next, recall that $\frac{ds}{dt} = s'(t) = |\vec{r}\ '(t)|$. This gives
\begin{equation*}
  \frac{d\vec{T}}{ds} = \frac{T'(t)}{|r'(t)|}
\end{equation*}
Taking absolute valus of both sides gives the following important \textbf{curvature formula:}
\begin{equation}\label{eq:curvature-formula}
  \boxed{\kappa(t) = \frac{|T'(t)|}{|r'(t)|}}
\end{equation}

\begin{example}[Curvature of a line]
  \label{ex:curvature-line}

  Consider a line in 3d space. This takes the form
  \begin{equation*}
    r(t) = vt+p
  \end{equation*}
  We can write out the above equation as:
  \begin{equation*}
    \begin{bmatrix}
      x\\y\\z
    \end{bmatrix}
    =
    \begin{bmatrix}
      v_{1}\\v_{2}\\v_{3}
    \end{bmatrix}
    t
    +
    \begin{bmatrix}
      x_{0}\\y_{0}\\z_{0}
    \end{bmatrix}
  \end{equation*}
  where $v= \left\langle v_{1},v_{2},v_{3} \right\rangle $ is a nonzero vector giving the direction of
  the line, and $p=(x_{0},y_{0},z_{0})$ is a point the line passes through.

  \fl{Question:} What is the curvature of the line?

  We want to apply \cref{eq:curvature-formula}. First observe that 
  \begin{equation*}
    r'(t)  = v
  \end{equation*}
  Therefore
  \begin{equation*}
    T(t) = \frac{v}{|v|} = \left\langle \frac{v_{1}}{|v|}, \frac{v_{2}}{|v|}, \frac{v_{3}}{|v|}  \right\rangle .
  \end{equation*}
  This does not depend on $t$. Therefore
  \begin{equation*}
    T'(t) = \left\langle 0,0,0 \right\rangle 
  \end{equation*}
  Therefore by \cref{eq:curvature-formula},
  \begin{equation*}
    \kappa(t)  = 0
  \end{equation*}
  for all $t$.

  This makes sense: a straight line never changes direction. So of course under any reasonable definition
  of ``curvature'', the curvature of a straight line should be zero.
\end{example}


\begin{example}[Curvature of a circle]
  \label{ex:curvature-circle}
  Consider a circle of radius $a>0$. We can parametrized this with
  \begin{equation*}
    \vec{r}(t) = \left( a\cos(t),a\sin(t) \right) 
  \end{equation*}
  What ``should'' the curvature be? It should be
  \begin{itemize}
    \item constant
    \item inversely related to $a$
  \end{itemize}
  Indeed, we can compute this and we get $\kappa(t) = \frac{1}{a}$ for all $t$. See example 3 on page 904
  of the text.
\end{example}




\begin{proposition}[A very useful formula for curvature]
  \label{prop:very-useful-formula-for-curvature}
  \begin{equation*}
    \kappa(t) = \frac{|r'(t)\times r''(t)|}{|r'(t)|^{3}}
  \end{equation*}
\end{proposition}


\begin{example}[twisted cubic curvature]
  \label{ex:twisted-cubic-curvature}
  Let
  \begin{equation*}

  We already showed that

    r'(t) = \left\langle 2,2t,t^{2} \right\rangle

  and so
  \begin{equation*}
    |r'(t)| = \sqrt{4+4t^{2}+t^{4}} = 2+t^{2}

    \kappa(t) = \frac{|T'(t)|}{|r'(t)|}
  \end{equation*}
  But this is going to be a lot of work to take all those derivatives. So instead, let's use

The next proposition summarizes an important geometric fact

\begin{proposition}
  Suppose $C$ is any curve on the surface of a sphere in 3d space. The sphere has some radius $c>0$,
  which is a constant. Suppose $C$ is parameterized by the vector function
  \begin{equation*}
    \vec{r}(t) =
    \begin{bmatrix}
      x(t)\\y(t)\\z(t)
    \end{bmatrix}
  \end{equation*}
  for $t\in (-\infty,\infty)$.

  \textbf{Claim:} $\vec{r}'(t)$ and $\vec{r}(t)$ are orthogonal.

  Why?

  Observe that
  \begin{equation*}
    \vec{r}(t)\cdot \vec{r}(t)= |\vec{r}(t)|^{2} = c^{2}
  \end{equation*}
  Differentiate both sides and use the chain rule. You get that $\vec{r}\ '(t)\cdot \vec{r}(t)=0$, which
  implies the two vectors are orthogonal
\end{proposition}

The direction that a curve is turning is given by the \demph{principal unit normal vector $N(t)$},
defined as
\begin{equation*}
  \vec{N}(t) = \frac{\vec{T}'(t)}{|\vec{T}'(t)|}
\end{equation*}

This vector is normal to $T(t).$ This is because $T(t)$ is a vector on the unit sphere and therefore is
perpendicular to its derivative, $\vec{T}'(t)$. 


\subsection{Motion in space: velocity and acceleration}
\begin{example}
  A stone  is dropped form a $1600$ foot high building.
  \begin{enumerate}[(a)]
    \item Find, as functions of time, its position and velocity.
    \item When does it hit the ground?
    \item How fast is it going when at that time?
  \end{enumerate}
  You may assume that acceleration due to gravity is $32 \mbox{ft/sec}^{2}$.

  \fl{Part (a):} Let
  \begin{align*}
    s(t)&=\mbox{position}\\
    v(t)&=\mbox{velocity}\\
    a(t)&=\mbox{acceleration}
  \end{align*}

  Then $a(t) = \frac{dv}{dt} = -32$ (negative because the direction is downward). So
  \begin{equation*}
    v(t) = \int a(t) dt = \int -32 dt = -32t +C_{0}
  \end{equation*}
  Since the stone was dropped, not thrown, its initial velocity was zero, i.e.,
  \begin{equation*}
    v(0) = 0.
  \end{equation*}
  Therefore $C_{0} =0$, and it follows that
  \begin{equation*}
    \boxed{v(t) = -32t}
  \end{equation*}

  Next we integrate velocity to find position:
  \begin{equation*}
    s(t) = \int v(t)dt = \int -32t dt = -16t^{2}+C_{1}
  \end{equation*}
  Since the stone started at height $1600$, we have
  \begin{equation*}
    s(0) = 1600.
  \end{equation*}
  Therefore
  \begin{equation*}
    100 = -16(0)^{2}+C_{1}
  \end{equation*}
  so $C_{1} = 1600$.
  Thus,
  \begin{equation*}
    \boxed{s(t) = -16t^{2}+1600.}
  \end{equation*}
  \fl{Part (b):} Let $t^{*}$ be the time that the stone hits the ground. It must be the case that
  \begin{equation*}
    s(t^{*}) = 0.
  \end{equation*}

A function of one variable takes in one real number and spits out a real
number. A function of two variables takes in two real numbers and spits out a
real number.


Given a function of two variables $f(x,y)$, we say that $x,y$ are the
\demph{independent variables}, and $z=f(x,y)$ is the dependent variable. The
domain of $f$ is some subset of the $xy$-plane. We can denote this by $D_{f}$.

For example, the function
\begin{equation*}
  f(x,y) = \frac{\sqrt{x+y+1}}{x-1}
\end{equation*}
has domain 
\begin{equation*}
  D_{f} = \left\{(x,y)\in \R^{2}: x\neq 1\right\}
\end{equation*}
What about the domain of the following function?
\begin{equation*}
  f(x,y)= x \log \left( x^{2}-y \right) 
\end{equation*}
We can find the domain $D_{f}$ of $f$ by recalling that $\log(u)$ is defined only for $u>0$. Thus, we
require that $x^{2}-y>0$, or $y<x^{2}$. [Plot this].

The \demph{range} of $f$ is the set of values that $f(x,y)$ can take. That is, it is
the set
\begin{equation*}
  \left\{ f(x,y): (x,y) \in D_{f} \right\}
\end{equation*}

Let $f$ be a function of two variables. For any constant $k$ in the range of $f$, the \demph{k-level curve} of a
function of two variables $f=f(x,y)$ is the set
\begin{equation*}
  \left\{ (x,y)\in D_{f} : f(x,y) = k \right\}.
\end{equation*}
In words, this is the set of points $(x,y)$ in the domain of $f$ satisfying
\begin{equation*}
  f(x,y) = k
\end{equation*}
for fixed value of $k$. Often, this traces out a curve in the $xy$-plane.

\subsection{Section 14.2: Limits and Continuity}
How should we define limits and continuity for functions of several variables?

If $P = (p_{1},p_{2}),Q =(q_{1},q_{2})$ are two points, let's denote
\begin{equation*}
  \text{dist}(P,Q) = \sqrt{(p_{1}-q_{1})^{2}+(p_{2}-q_{2})^{2}}
\end{equation*}
as the \textbf{distance} between $P$ and $Q$.

Intuitively, for a function of two variables, we want to define the limit
$L = \lim_{(x,y)\to (a,b)}f(x,y)$ as the number which the function value
$f(x,y)$ approaches as the point $(x,y)$ gets closer and closer to the point
$(a,b)$.

For a function $g$ of a single variable, we recall a condition involving the
left and right-hand limits:
\begin{empheq}[box=\boxmath]{gather*}
  \lim_{x \to a}g(x) \text{ exists}\\
  \text{if and only if }\\
  \lim_{x \to a^{+}}g(x) \text{ and }\lim_{x \to a^{-}}g(x) \text{ exist and are equal}
\end{empheq}

The issue was that sometimes a function $g(x)$ will approach different values
depending at a point $a$ on whether $x \to a$ from the left or from the right.
For example, consider the function
\begin{equation*}
  g(x) = \left\{ \begin{array}{l@{\quad:\quad}l} 0 & x< .4 \\2.5 &x \geq .4\end{array}\right.
\end{equation*}
which has graph

\begin{definition}[limit]
  Let $f=f(x,y)$ be a function of two variables with domain $D_{f}$, and we
  consider some point $(a,b)$ in the plane. Consider a sequence of points
  \begin{equation}\label{eq:14}
    (x_{1},y_{1}), (x_{2},y_{2}), (x_{3},y_{3}),\ldots
  \end{equation}
  such that each point $(x_{n},y_{n})$ is in $D_{f}$, and such that the points
  are getting closer to $(a,b)$ in the sense that
  \begin{equation*}
    \text{dist}((x_{n},y_{n}),(a,b)) \to 0 \text{ as } n \to \infty.
  \end{equation*}
  If
  \begin{equation*}
    \lim_{n\to\infty} f(x_{n},y_{n}) = L.
  \end{equation*}
  for ANY SUCH SEQUENCE from \cref{eq:14}, then we say that \demph{$L$ is the
    limit of $f(x,y)$ as $(x,y) \to (a,b)$,} and we write
  \begin{equation*}
    \lim_{(x,y)\to (a,b)} f(x,y) = L
  \end{equation*}
  or equivalently,
  \begin{equation*}
    f(x,y) \to L \text{ as } (x,y) \to (a,b).
  \end{equation*}
  On the other hand, if the above condition is not satisfied, then we say that
  the limit \demph{does not exist (DNE).} In particular, if there are two
  different sequences
  \begin{equation*}
    (x_{1},y_{1}),(x_{2},y_{2}),(x_{3},y_{3}),\ldots
  \end{equation*}
  and
  \begin{equation*}
    (\tilde{x}_{1},\tilde{y}_{1}),(\tilde{x}_{2},\tilde{y}_{2}),(\tilde{x}_{3},\tilde{y}_{3}),\ldots
  \end{equation*}
  with
  \begin{equation*}
    \lim_{n\to\infty} f(x_{n},y_{n})\neq \lim_{n\to\infty} f(\tilde{x}_{n},\tilde{y}_{n})
  \end{equation*}
  then we say that the limit $\lim_{(x,y)\to (a,b)}f(x,y)$ does not exist.
  [This is directly analogous to the limit of a single-variable function not
  existing if the left and right hand limits don't agree.]
\end{definition}


Moreover, we say that $f(x,y)$ is \demph{continuous at $(a,b)$} if
\begin{equation*}
  \lim_{(x,y) \to (a,b)}f(x,y)\text{ exists and equals }f(a,b)
\end{equation*}
Intuitively, this notion of continuity amounts to the idea that if we perturb
the point $(a,b)$ by an infinitesimal change in the $x$ and $y$ (call them
$dx$ and $dy$), then the value of the function changes by at most an
infinitesmial amount:
\begin{equation*}
  f(a+dx, b+dy) \text{ is infinitesimally close to the original point } f(a,b).
\end{equation*}

It is hard to show that a function of two variables is continous at a point,
because doing so requires considering all possible paths of approach. So there
are lots of ways things can go wrong. A classic example:

\begin{example}
  \label{ex:aaa}
  Let
  \begin{equation*}
    f(x,y) = \frac{x^{2}-y^{2}}{x^{2}+y^{2}}.
  \end{equation*}
  Does the limit
  \begin{equation*}
    \lim_{(x,y)\to (0,0)}f(x,y) 
  \end{equation*}
  exist?

  \Fl{Answer:} No, for the following reason:
  \begin{itemize}
    \item Approach along the $x$-axis (i.e., when $y=0$) and you get
    \begin{equation*}
      f(x,y) \to 1 \text{ as } (x,y)\to (0,0) \text{ along the $x$-axis}
    \end{equation*}
    \item Approach along the $y$-axis, and you get $-1$.
  \end{itemize}
  Since these are not equal, the limit does not exist.
\end{example}

\begin{example}
  What about the limit as $(x,y)\to (0,0)$ of the function
  \begin{equation*}
    f(x,y) = \frac{xy^{2}}{x^{2}+y^{4}}?
  \end{equation*}
  \Fl{No.} First, let's try approaching along any line $y = mx$. In that case
  we get
  \begin{align*}
    \lim_{\overset{(x,y)\to (0,0)}{y=mx}}f(x,y) 
    &= \lim_{x \to 0} f(x,mx) \\
    &= \lim_{x \to 0} \frac{m^{2}x^{3}  }{x^{2}+m^{4}x^{4}} \\
    &= \lim_{x \to 0} \frac{m^{2}x  }{1+m^{4}x^{2}} \\
    &= 0
  \end{align*}

    \lim_{\overset{(x,y)\to (0,0)}{x=y^{2}}}f(x,y)
    &=\lim_{y \to 0}f(y^{2},y)\\
    &=\lim_{y \to 0}\frac{y^{4}}{y^{4}+y^{4}}\\
    &=\frac{1}{2}.
  \end{align*}

  $\lim_{(x,y)\to (0,0)}f(x,y)$ does not exist.
\end{example}

\begin{example}
  \label{ex:later}
  What about the limit as $(x,y)\to (0,0)$ of
  \begin{equation*}
    f(x,y) = \frac{3x^{2}y}{x^{2}+y^{2}}
  \end{equation*}
  \Fl{Yes.} The limit is zero. We will use the squeeze theorem. First observe that
  \begin{align*}
    |f(x,y)|
    &= \left| \frac{3x^{2}y}{x^{2}+y^{2}} \right|\\
    &\leq  3|y| \left( \frac{x^{2}}{x^{2}+y^{2}} \right)\\ 
    &\leq 3|y|\\
    &\leq 3 \sqrt{x^{2}+y^{2}}\\
    &= 3 \text{dist}((x,y),(0,0))
  \end{align*}
  Therefore, as $(x,y) \to (0,0)$, it follows that $|f(x,y)| \to 0$. This
  doesn't depend on the path by which $(x,y)$ might approach $(0,0)$. After
  all, recall what it means for $(x,y) \to (0,0)$; it means that
  $\text{dist}((x,y),(0,0))\to 0$.

  \begin{equation*}
    -|f(x,y)| \leq f(x,y) \leq |f(x,y)|.
  \end{equation*}
\end{example}

\subsection{Continuity}
 \textit{Section 14.2}


A function of two variables $f$ is \demph{continuous at $(a,b)$} if
\begin{equation*}
  \lim_{(x,y) \to (a,b)}f(x,y)\text{ exists and equals }f(a,b)
\end{equation*}
A function is \demph{continuous} if it is continuous at every point in its
domain.

Intuitively, this notion of continuity amounts to the idea that if we perturb
the point $(a,b)$ by an infinitesimal change in the $x$ and $y$ (call them
$dx$ and $dy$), then the value of the function changes by at most an
infinitesmial amount:
\begin{equation*}
  f(a+dx, b+dy) \text{ is infinitesimally close to the original point } f(a,b).
\end{equation*}

As a practical matter, if we know that $f$ is continuous at a point $(a,b)$,
then we can evaluate the limit
\begin{equation*}
  \lim_{(x,y)\to (a,b)}f(x,y)
\end{equation*}
by simply plugging in $x=a$ and $y=b$. For example,

\begin{example}[Polynomial functions]
  Let
  \begin{equation*}
    f(x,y)=x^{2}y^{3}-x^{3}y^{2}+3x+2y
  \end{equation*}
  Suppose we want to know
  \begin{equation*}
    \lim_{(x,y)\to (1,2)} f(x,y).
  \end{equation*}

  \textbf{Fact:} polynomials are always continuous.

  Since $f$ is a polynomial (of two variables, $x$ and $y$), it is continuous.
  Therefore, we can just plug in $x=1$ and $y=2$ to find the limit:
  \begin{equation*}
    \lim_{(x,y)\to (1,2)} f(x,y) =  f(1,2) = 8-4+3+4=11.  
  \end{equation*}
  Polynomials of multiple variables are a deep an interesting field of study.
\end{example}

\Fl{Fact:} We can combine continuous functions together (e.g., by
adding/subtracting them, multipying/dividing them, and by function
composition), and the resulting function will be continuous on its domain.


\begin{example}[Rational functions]
  Consider the function
  \begin{equation*}
    f(x,y) = \frac{x^{2}-y^{2}}{x^{2}+y^{2}}.
  \end{equation*}
  This is an example of a \demph{rational function}, which is a quotient of
  two polynomials. At what points in the $xy$-plane is the function $f$ continuous?
  \begin{itemize}
    \item $f$ is a rational function, and therefore it is continuous at all
    points on its domain, which is
    \begin{equation*}
      D_{f} =  \left\{(x,y)\in \R^{2}: (x,y)\neq (0,0)\right\}
    \end{equation*}
    \item $f$ is not defined at $(0,0)$ and is therefore not continuous at
    that point.
  \end{itemize}

  What if we modifed $f$ so that it was defined at the point $(0,0)$? That is,
  consider the function
  \begin{equation*}
    g(x,y) 
    = \left\{ 
      \begin{array}{l@{\quad:\quad}l} \frac{x^{2}-y^{2}}{x^{2}+y^{2}} & (x,y)\neq (0,0)\\
        0 & (x,y)=(0,0) \end{array}\right.
  \end{equation*}
  In this case, $g$ is \textit{still} not continuous at $(0,0),$ because the
  limit doesn't exist (we showed this in \cref{ex:aaa}).
\end{example}

\begin{example}

  \begin{itemize}

    \item At the point $(0,0)$ it is continuous, since we showed in an

    \begin{equation*}

  \end{itemize}

\begin{definition}[Partial derivatives]
  Let $f=f(x,y)$ be a function of two variables, called $x$ and $y$.
  % Let
  % $(a,b)\in \R^{2}$ be a point in the domain of $f$. The
  % \demph{partial derivative of $f$ with respect to $x$ at the point $(a,b)$} is
  % \begin{equation*}
  %   f_{x}(a,b) :=\lim_{h \to 0}\frac{f(a+h,b)-f(a,b)}{h}.
  % \end{equation*}
  % The partial derivative of $f$ with respect to $x$ at $(a,b)$ is

  %   f_{y}(a,b):=\lim_{h \to 0}\frac{f(a,b+h)-f(a,b)}{h}.

  The \demph{partial derivative of $f$ with respect to the variable $x$} is a
  function, denoted $f_{x}$, defined by
  \begin{equation*}
    f_{x}(x,y) = \lim_{h \to 0} \frac{f(x+h,y)-f(x,y)}{h}
  \end{equation*}
  The \demph{partial derivative of $f$ with respect to $y$ } is the function
  $f_{y}$ defined by
  \begin{equation*}
    f_{y}(x,y)= \lim_{h \to 0} \frac{f(x,y+h)-f(x,y)}{h}
  \end{equation*}
  Alternative notation:
  \begin{equation*}
    \frac{\partial f}{\partial x} = f_{x}
    \quad \text{and} \quad
    \frac{\partial f}{\partial y} = f_{y}
  \end{equation*}

\subsection{A Trick: Implicit Differentiation}
Assume that $z=f(x,y)$ is a function of two independent variables $x$ and
$y$. Suppose we don't know what $f$ is, but we do know that $x,y$ and
$z$ obey the relation
\begin{equation*}
  yz - \log(z) - x - y = 0.
\end{equation*}
Find $\frac{\partial z}{\partial x} = f_{x}(x,y)$.

\fl{Solution:} Differentiate both sides with respect ot $x$,
pretending that $y$ is a constant and remembering that $z=f(x,y)$:
\begin{equation*}
  \frac{\partial }{\partial z}\left[ yz - \log(z) - x - y  \right] =0.
\end{equation*}
or
\begin{equation*}
  \frac{\partial }{\partial x}\left[ yz  \right]  - \frac{\partial }{\partial x}\left[ \log(z) \right]  - \frac{\partial }{\partial x}\left[ x \right]  - \frac{\partial }{\partial x}\left[ y \right]  =0.
\end{equation*}
or
\begin{equation*}
  y\frac{\partial z}{\partial x}  - \frac{1}{z}\frac{\partial z}{\partial x}  - 1=0.
\end{equation*}
Solving for $\frac{\partial z}{\partial x}$ gives
\begin{equation*}
  \frac{\partial z}{\partial dx} = \frac{1}{y-\frac{1}{z}} = \frac{z}{yz-1}.
\end{equation*}
\subsection{Tangent Planes and Linear Approximations}
\textit{Section 14.4 Tangent planes and linear approximations}

A central idea in calculus is approximating curvy things with straight things.
Here we will discuss approximations of curvy surfaces by their tangents planes. 

\Fl{Tangent lines:} Let $f= f(x)$ be a function of a single variable. Let $C$
be the curve (the graph) defined by $f$. And let $(x_{0},y_{0})$ be a which
the curve passes through. The \demph{tangent line} at the point $(x_{0},y_{0})$ is
given by the formula
\begin{equation*}
  y-y_{0} = f'(x_{0})(x-x_{0}).
\end{equation*}


\Fl{Tangent planes:} Let $f=f(x,y)$ be a function of two variables, whose
graph defines a smooth surface $S$. Let $(x_{0},y_{0},z_{0})$ be a point on
$S$. The \demph{tangent plane} at the point $(x_{0},y_{0},z_{0})$ is the plane
defined by
\begin{equation*}
  z-z_{0} = f_{x}(x_{0},y_{0})(x-x_{0})+f_{y}(x_{0},y_{0})(y-y_{0}).
\end{equation*}
This is the plane which satisfies the following two properties
\begin{itemize}
  \item it passes through the point $(x_{0},y_{0},z_{0})$
  \item its tilt matches the surfaces as much as possible (i.e, the slope of
  the plane in the $x$-direction is $f_{x}(x_{0},y_{0})$, and the slope of the
  plane in the $y$-direction is $f_{y}(x_{0},y_{0})$).
\end{itemize}
Recall that planes have equations of the form
\begin{equation*}
  A(x-x_{0})+B(y-y_{0})+C(z-z_{0})=D
\end{equation*}
so this is really a plane. 

\begin{example}
  Let $f(x,y) = 2x^{2}+y^{2}$. Then the surface $z=f(x,y)$ is an elliptic
  paraboloid (like a bowl) which contains the point $(1,1,3)$. Find the
  tangent plane at the point $(1,1,3)$.
\end{example}

\subsection{First Order Taylor Approximations}
\textit{AKA ``linear approximations'', Section 14.4 in the textbook}


Recall: If $f=f(x)$ is differentiable at the point $a\in \R$, then by
Taylor's Theorem we have
\begin{equation*}
  f(x) \approx
  \underbrace{f(a)+f'(a)(x-a)}_{\text{1st degree
      Taylor polynomial}}
\end{equation*}
when $(x,y) \approx (a,b)$. But Taylor's theorem says that if $f$ is
\demph{twice} differentiable at $a\in \R$, then an even better approximation holds:
\begin{equation*}
  f(x) \approx
  \underbrace{f(a)+f'(a)(x-a)+\frac{f''(a)}{2!}(x-a)^{2}}_{\text{2nd degree
      Taylor polynomial}}
\end{equation*}
when $(x,y) \approx (a,b)$. We can keep going if $f$ is three or four or more
times differentiable at $a$. But for most applications, the degree 2
approximation is sufficient. This approximation tends to be very good. For
example:

Let $f(x) = e^{x}$. The second degree taylor approximation at $x=0$ is:
\begin{equation*}
  e^{x} \approx 1+x+\frac{x^{2}}{2}.
\end{equation*}
If $x=1/10$, then $e^{x}\approx 1.1051871$. The approximation on the right
hand side is
\begin{equation*}
  1+\frac{1}{10}+\frac{1}{200} = 1.105
\end{equation*}
These differ by only about $\frac{1}{100}$th of a percent of the true value.
This approximation gets better as $x \to 0$.

$f(x) = \cos(x)$ at $x=0$:

We can use tangent planes to approximate smooth functions. Suppose that $f=f(x,y)$ is
a ``smooth'' function of two variables. If $(x,y)$ is close to $(a,b)$, then
\begin{equation}\label{eq:13}
  f(x,y) \approx \underbrace{f(a,b) + f_{x}(a,b)(x-a)+ f_{y}(a,b)(y-b)}_{L(x,y)}
\end{equation}
The right hand side of \cref{eq:13} is denoted $L(x,y)$ and goes by many
names:
\begin{itemize}
  \item the \demph{linear approximation} of $f$ at $(a,b)$
  \item the \demph{tangent plane approximation} of the $f$ at $(a,b)$
  \item the \demph{linearization} of $f$ at $(a,b) $
  \item the \demph{first order Taylor approximation} for $f$ near $(a,b)$
\end{itemize}


\begin{example}
  Find the linearization of
  \begin{equation*}
    f(x,y) = x^{2}-xy+\frac{1}{2}y^{2}+3
  \end{equation*}
  at the point $(3,2)$.
\end{example}

\begin{example}
  Find the first order Taylor polynomial for $f(x,y) = 2x^{2}+y^{2}$ at
  $(1,1)$ and use it to approximate $f(1.1,0.95)$.

  \begin{align*}
    L(x,y) 
    &= f(1,1)+f_{x}(1,1)(x-1)+f_{y}(1,1)(y-1)\\
    &3+4(x-1)+2(y-1)
  \end{align*}
  And
  \begin{align*}
    f(1.1,0.95) 
    &\approx L(1.1,0.95)\\
    &=3+4(.1)+2(-.05)\\
    &=3+.4-.1\\
    &=3.3
  \end{align*}
  (And indeed, we have $f(1.1,0.95)=3.3224$ so the approximation is pretty
  good.)
\end{example}

\Fl{What does it mean for a function $f$ to be differentiable/smooth?}

The quality of this approximation depends on the function $f$ being
``smooth'', which I haven't defined. Informally, we say that a
function $f=f(x,y)$ of two variables is \demph{differentiable} at a point
$(a,b)$ if, when we zoom in on the graph of $f$ near $(a,b)$, the
graph of $f$ looks like a plane. If that's the case, then we say that
$f$ is \demph{differentiable} at $(a,b)$.


More precisely, we say that $f$ is \demph{differentiable} at $(a,b)$ if
\begin{equation*}
  \lim_{(x,y)\to (a,b)} \frac{|f(x,y)-L(x,y)|}{\text{dist}((x,y),(a,b))} =0 
\end{equation*}
where $\text{dist}((x,y),(a,b)) = \sqrt{(x-a)^{2}+(y-b)^{2}}$.

Intuitively, differentiable functions are functions for which the linearization $L(x,y)$ is
a good approximation.

Differentiability can be hard to show.


\fl{A useful criterion:} if
$f_{x}$ and $f_{y}$ exist and are continuous at $(a,b)$ then $f$ is
differentiable at $(a,b)$.

\subsection{Chain Rule}
\textit{Section 14.5 }

\begin{theorem}[The Chain Rule]
  \label{thm:chain-rule}
  Suppose that $z=f(x,y)$ is a differentiable function of $x$ and $y$, which
  are themselves functions of a third variablle $t$:
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=x(t) \\ y=y(t) \end{array}\right.
  \end{equation*}
  Assume that $x(t),y(t)$ are both differentiable. Then $z$ is a
  differentiable function of $t$, and
  \begin{equation*}
    \frac{dz}{dt} = \frac{\partial f}{\partial x} \frac{dx}{dt} +\frac{\partial f}{\partial y} \frac{dy}{dt}
  \end{equation*}
\end{theorem}

Let's consider a concrete example:

\begin{example}
  Consider the parameterized curve
  \begin{equation*}
    \left\{ \begin{array}{l@{}l} x=\sin(2t) \\ y=\cos(t) \end{array}\right.
  \end{equation*}
  for $0 \leq \tau \leq 2\pi$. This is the following figure-8 shaped curve:
  \begin{center}
    \includegraphics[scale=0.7]{images/first-chain-rule-example}
  \end{center}
  In addition, suppose 
  \begin{equation*}
    z = x^{2}y+3xy^{4}.
  \end{equation*}
  Find $\frac{dz}{dt}$ when $t=0$.
\end{example}


\begin{example}
  Let $z=e^{x}\sin(y)$, where $x=st^{2}$ and $y=s^{2}t$. To be clear, we are
  regarding $s,t$ as independent variables. The variables $x,y$ are functions of
  both $s$ and $t$. Find $\frac{\partial
    z}{\partial s}$ and $\frac{\partial z}{\partial t}$.

  Then
  \begin{align*}
    \frac{\partial z}{\partial s} 
    &= \frac{\partial z}{\partial x} \frac{\partial x}{\partial s}+ \frac{\partial z}{\partial y}\frac{\partial y}{\partial s}\\
    &= \left( e^{x}\sin(y) \right) \left( t^{2} \right)+ \left( e^{x}\cos(y) \right) \left( 2st \right)\\    
    &= t^{2}e^{x}\sin(y)+ 2ste^{x}\cos(y)\\
    &= t^{2}e^{st^{2}}\sin(s^{2}t)+2st e^{st^{2}}\cos(s^{2}t)
  \end{align*}
  
\end{example}

\subsection{A new perspective (and a new formula for) on implicit
  differentiation}

Suppose we have the equation
\begin{equation*}
  x^{3}+y^{3} = 6xy
\end{equation*}
This equation defines the following curve on the plane:
\begin{center}
  \includegraphics[scale=0.3]{images/loop-dee-loop}
\end{center}

We assume that $y$ is a function of $x$ and we want to compute the slope. In
implicit differentiation, we apply the differentiation operator $\frac{d}{dx}$
to both sides, which gives
\begin{equation*}
  3x^{2}+3y^{2}\frac{dy}{dx} = 6y+6x \frac{dy}{dx}
\end{equation*}
Then we solve for $\frac{dy}{dx}$:
\begin{align*}
  \frac{dy}{dx} 
  &= \frac{3x^{2}-6y}{3y^{2}+6x}\\
  &= \frac{x^{2}-2y}{y^{2}+2x}\\
\end{align*}
This is all very nice. Here's another way to do this same problem, using the
\textbf{Chain Rule:}

First, define a new function $F$ of two variables:
\begin{equation*}
  F(x,y) = x^{3}+y^{3} - 6xy
\end{equation*}

So our curve is
\begin{equation*}
  F(x,y) = 0.
\end{equation*}
Now, assuming that $x$ is an independent variable and that $y$ is a function
of $x$ (so that $\frac{d}{dx}[y] = \frac{dy}{dx}$, but $\frac{d}{dx}[x]= 1$),
we have
\begin{equation*}
  \frac{d}{dx} \left[ F(x,y) \right]= 0 
\end{equation*}
and this gives us
\begin{equation*}
  \frac{\partial F}{\partial x} \frac{dx}{dx} + \frac{\partial F}{\partial x} \frac{dy}{dx} = 0
\end{equation*}
which simplifies to
\begin{equation*}
  F_{x}(x,y)+ F_{y}(x,y) \frac{dy}{dx} = 0
\end{equation*}
and gives us the nice formula
\begin{empheq}[box=\boxmath]{equation*}
  \frac{dy}{dx} = -\frac{F_{x}(x,y)}{F_{y}(x,y)}
\end{empheq}
Does it really work? Here, we have $F_{x}(x,y) = 3x^{2}-6xy$ and $F_{y}(x,y)
=3y^{2}-6x$; plugging these into the above formula gives us the same answer as
earlier.  Cool. The boxed formula is a little strange at first, because of the
negative sign and the way the partial derivatives feel like they are in the
wrong place.


\subsection{Directional Derivatives}
Given a function $z=f(x,y)$, we now know how to find the rate of change of $z$
when moving in the $x$ or $y$ directions (i.e., East or North)---namely, we find  $f_{x}$ and
$f_{y}$. But what if we wanna know the rate of change some other direction???

For example, suppose that the $(x,y)$-plane is the ocean, so that each point
$(x,y)$ is the coordinates of some location. And suppose that $z$ is the
surface temperature of the water at that location. So $z=f(x,y)$ is continuous
(no jumps!). But say I want to know the rate of change of the surface
temperature if I pilot my boat northwest? Or any other random direction?


\begin{definition}[Directional derivative]
  The \demph{directional derivative} of $f$ at $(x,y)$ in the
  direction of a vector $\vec{u}=\left\langle a,b \right\rangle$ is
  \begin{equation*}
    D_{\vec{u}}f(x,y) = \lim_{h \to 0} \frac{f(x+ha,y+hb)-f(x,y)}{h} 
  \end{equation*}
  provided that this limit exists.
\end{definition}

\begin{proposition}
  If $\bar{u} = \left\langle a,b \right\rangle$ is a \textbf{unit vector}, then
  \begin{equation*}
    D_{\vec{u}}f(x,y) = af_{x}(x,y)+ bf_{y}(x,y)
  \end{equation*}
  (provided that $f$ is differentiable).
\end{proposition}

In the nicest case, we represent the direction with a vector
\begin{equation*}
  \vec{u} = \left\langle \cos(\alpha),\sin(\theta) \right\rangle 
\end{equation*}
in which case
\begin{equation*}
  D_{u}f(x,y) = f_{x}(x,y)\cos(\theta)+f_{y}(x,y)\sin(\theta)
\end{equation*}

\begin{example}
  Find the directional derivative of
  \begin{equation*}
    f(x,y) = x^{3}-3xy+4y^{2}
  \end{equation*}
  in the direction of $\theta=\frac{\pi}{6}$, i.e., $\vec{u} = \left\langle
    \cos(\frac{\pi}{6}),\sin(\frac{\pi}{6}) \right\rangle  = \left\langle \frac{\sqrt{3}}{2},\frac{1}{2} \right\rangle $
\end{example}


\subsection{Gradient Notation}

\begin{definition}
  Let $f=f(x,y)$. The \demph{gradient} of $f$, denote $\nabla f$, is the
  vector of partial derivatives:
  \begin{equation*}
    \nabla f =
    \begin{bmatrix}
      f_{x}\\f_{y}
    \end{bmatrix}
  \end{equation*}
  To be clear, $\nabla f$ is itself a function $x$ and $y$:
  \begin{equation*}
    \nabla f(x,y) =
    \begin{bmatrix}
      f_{x}(x,y)\\f_{y}(x,y)
    \end{bmatrix}
  \end{equation*}
\end{definition}
Using this notation, we have
\begin{equation*}
  f(x,y) \approx f(a,b) + \nabla f(a,b)\cdot
  \begin{bmatrix}
    x-a\\y-b
  \end{bmatrix}
\end{equation*}


\begin{example}

  \begin{equation*}
    f(x,y) = x^{2}y^{3}-4y
  \end{equation*}
  at the point $(2,-1)$ in the direction of hte vector $\vec{v} = 2\vec{\imath}+5\vec{\jmath} $

as possible. Wherever the ant is on the surface, it needs to walk in the direction
which gives the fastest increase in eleveation (i.e., the steepest path).

We want to find the unit vector $u$ which maximizes $D_{u}f$. Suppose $u$ and
$\nabla f$ form an angle of $\theta$. Then
\begin{align*}
  D_{u} f 
  &= \nabla f\cdot u \\
  &=  |\nabla f| |u| \cos(\theta)\\

\end{align*}

direction. But this implies that $u$ must be the vector
\begin{equation*}
  u = \frac{\nabla f(x,y)}{|\nabla f(x,y)|}.
\end{equation*}

\subsection{The gradient vector is \textit{orthogonal to level curves}}


Recall that the chain rule statese that if $z=f(x(t),y(t))$, then
\begin{equation*}
  \frac{dz}{dt} = \frac{\partial f}{\partial x} \frac{dx}{dt} +\frac{\partial f}{\partial y} \frac{dy}{dt}
\end{equation*}
Also recall that two vectors are orthogonal if their dot product is zero.

\begin{theorem}
  Fix $k\in \R$ and consider the level curve $C$ given by the formula
  \begin{equation*}
    f(x,y) =k.
  \end{equation*}
  To be precise, $C$ is a curve in the $(x,y)$-plane consisting of all
  points $(x,y)$ which satisfy $f(x,y) = k$.

  
  If $(a,b)$ is any point on $C$, the vector $\nabla f(a,b)$ is orthogonal to the
  level curve at that point.
\end{theorem}

\begin{proof}
  Let $\gamma(t) = \left\langle x(t),y(t) \right\rangle $ be a
  parameterization of $C$ (with $t$ in some interval $I$). Recall that
  $\gamma'(t)= \left\langle x'(t),y'(t) \right\rangle $ is the tangent vector
  to the curve. Also, since $\gamma(t)$ is a $k$-level curve, we have
  \begin{equation*}
    f(\gamma(t)) = f(x(t),y(t)) = k
  \end{equation*}
  for all $t$. Therfore $f(\gamma(t))$ is a \textit{constant} function of $t$.
  So it's derivative is zero:
  \begin{equation}\label{eq:15}
    \frac{d}{dt}\left[ f(\gamma(t)) \right] = 0 
  \end{equation}
  By the chain rule,
  \begin{align*}
    \frac{d}{dt} \left[ f(\gamma(t)) \right] 
    &= \frac{d}{dt}\left[ f(x(t),y(t)) \right]\\ 
    &= f_{x}(x(t),y(t)) x'(t) + f_{y}(x(t),y(t))y'(t)\\
    &= \nabla f(\gamma(t)) \cdot\gamma'(t)
  \end{align*}
  Combining this with \cref{eq:15}, it follows that for all $t$, 
  \begin{equation*}
    \nabla f(\gamma(t)) \cdot\gamma'(t) = 0.
  \end{equation*}
  In other words, at every point of the level curve, the tangent vector and
  the gradient vector are orthogonal.
\end{proof}

\subsection{``Optimizing'' a function of a single variable}

Suppose we wish to maximize the function 
\begin{equation*}
  f(x) = \frac{2}{3}x^{3}+\frac{5}{2}x^{2}-3x+1
\end{equation*}
on the interval $-10 \leq x \leq 2$.

\Fl{Find critical points:}
\begin{align*} 
  f'(x) 
  &= 2x^{2}+5x-3 \\
  &= (x+3)(2x-1)
\end{align*}
This is equal to zero when $x=-3$ or $x=\frac{1}{2}$. These are the critical
points.

\Fl{Classify critical points:}
\begin{equation*}
  f''(x) = 4x+5
\end{equation*}
Therefore $f''(-3) <0$ and $f''(\frac{1}{2})> 7$. Therefore the function is
concave down at $x=-3$ and concave up at $x=\frac{1}{2}$. This allows us to
conclude that $x=-3$ is a maximuma nd $x=\frac{1}{2}$ is a minimum.  This is
the second derivative test.

(If the second derivative were zero, we'd have an inflection point rather than
a maximum or minimum.)


\Fl{Compare with boundardy:}
We know that $x=-3$ is a local maximum, and $f(-3) = 19$. But is it the global
maximum? We need to compare with the endpoint of the domain
\begin{itemize}
  \item $f(-10) = -335.667$
  \item $f(2) = 12.333$
\end{itemize}
We can conlude that $x=-3$ is indeed the global maximum.

\subsection{Optimizing functions of multiple variables}
A function of two variables has a \demph{local maximum} at $(a,b)$ if
\begin{equation*}
  f(x,y) \leq f(a,b)
\end{equation*}
for all $(x,y)$ within some radius of the point $(a,b)$. The number $f(a,b)$
is the \demph{local maximum value.} The notion of \demph{local minimum} is
defined in a similar way.

\Fl{Fact:} Suppose $f$ is a function whose domain is an open set. If $f$ has a
local maximum or minimum at $(a,b)$ and the first-order parital derivatives of
$f$ exist there, then $f_{x}(a,b)=0$ and $f_{y}(a,b) =0$. In other words, the
tangent plane at the local optimum is horizontal.


A point $(a,b)$ is a \demph{critical point} (or: \demph{stational point}) of
$f$ if $f_{x}$ and $f_{y}$ are both zero, or if one of them doesn't exist.

\begin{example}
  Let $f(x,y) = x^{2}+y^{2}-2x-6y+14$. Find the critical points of $f$.

  Also by completing the square, we have:
  \begin{equation*}
    f(x,y) = 4+(x-1)^{2}+(y-3)^{2}
  \end{equation*}
  We can observe from this equation that $f(x,y)$ as a minimum at $(x,y )
  =(1,3)$ and that the minimum value is 4.
\end{example}

Recall that the Hessian of a function of two variables is the $2\times 2$
matrix
\begin{equation*}
  H_{f} = \begin{bmatrix}
    f_{xx}&f_{xy}\\
    f_{yx}&f_{yy}
  \end{bmatrix}
\end{equation*}


\begin{theorem}[Second Derivative Test]
  \label{thm:second-derivative-test}
  Let $f=f(x,y)$ be a function of two variables, and let $(a,b)$ be a
  critical point of $f$. Assume the entries of the Hessian exist and are all
  continuous, and let
  \begin{equation*}
    D = \det(H_{f}(a,b)) = f_{xx}(a,b)f_{yy}(a,b)- \left[ f_{xy}(a,b) \right]^{2}. 
  \end{equation*}
  Then there are three cases
  \begin{enumerate}[(i)]
    \item If $D>0$ and $f_{xx}(a,b)>0$, then $f(a,b)$ is a local minimum
    \item If $D>0$ and $f_{xx}(a,b)<0$, then $f(a,b)$ is a local maximum
    \item If $D<0$ then $f(a,b)$ is a saddle point (i.e., neither a maximum
    nor a minimum)
  \end{enumerate}
\end{theorem}

\begin{remark}[For those taking linear algebra]
  Whether the function $f$ has a minimum or maximum at $(a,b)$ is determined
  by the eigenvalues of the matrix $H_{f}(a,b)$. Condition (i) is equivalent
  to the eigenvalues of $H_{f}(a,b)$ both being positive. Condition (ii) is
  equivalent to the eigenvalues both being negative. Condition (iii) is
  equivalent to having one negative and one positive eigenvalue.
\end{remark}


\begin{example}
  Let
  \begin{equation*}
    f(x,y) = x^{2}+xy+y^{2}+y.
  \end{equation*}
  Find the critical points and classify them.

  \Fl{Solution:}

  \fl{Step 1.} Find the gradient:
  \begin{equation*}
    \nabla f =
    \begin{bmatrix}
      2x+y\\x+2y+1
    \end{bmatrix}
  \end{equation*}

  \fl{Step 2.} Set $\nabla f=0$ and solve for $(x,y)$:
  \begin{equation*}
    2x+y=0 \quad \text{and} \quad x+2y+1=0
  \end{equation*}
  so $y=-2x$ and hence $x=1/3$, and so $y=-2/3$.
  We have found one critical point:
  \begin{equation*}
    (x,y) = (\frac{1}{3},-\frac{2}{3}).
  \end{equation*}

  \fl{Step 3.} Classify the critical points using the second derivative test:
  \begin{equation*}
    H_{f}(x,y) =
    \begin{bmatrix}
      2&1\\1&2
    \end{bmatrix}
  \end{equation*}
  Therefore $D = H_{f}(\frac{1}{3},-\frac{2}{3})= 4-1 = 3>0$. Moreover,
  $f_{xx}(\frac{1}{3},-\frac{2}{3}) = 2>0$, so the second derivative test
  implies that the function is concave up at the critical point
  $(\frac{1}{3},-\frac{2}{3})$. Therefore, the critical point is a local minimum.
\end{example}


\begin{example}
  Find the local maximum and minimum values and saddle points of
  \begin{equation*}
    f(x,y) = x^{4}+y^{4}-4xy+1
  \end{equation*}
  \fl{Solution:} Critical points are $(0,0)$ (saddle point), $(-1,-1)$
  (local minimum), and $(1,1)$ (local minimum).
\end{example}

  Let's call this triangular region $D$.
  
  \Fl{General philosophy for this type of problem:} First, maximize the
  function on the interior of its domain. Then maximize it on the boundary of
  the domain (which we denoted $\partial D$). Then compare all the points and
  pick the one(s) that yeild the biggest value of the function.

  \fl{Interior:} we find the critical points by setting $\Delta f = 0$ and
  solving for $(x,y)$.
  \begin{equation*}
    \Delta f =
    \begin{bmatrix}
      2-2x\\4-2y
    \end{bmatrix}
    =
    \begin{bmatrix}
      0\\0
    \end{bmatrix}
  \end{equation*}
  This gives a single critical point $(x,y) = (1,2)$. This critical point is
  in $D$. (If it hadn't been in $D$, we would have thrown it out as irrelevelt
  to the problem at hand.)

  We classify the critical point using the second derivative test:
  \begin{equation*}
    H_{f}(x,y) =
    \begin{bmatrix}
      f_{xx}&f_{yx}\\
      f_{xy}&f_{yy}
    \end{bmatrix}
    =
    \begin{bmatrix}
      -2&0\\
      0&-2
    \end{bmatrix}
  \end{equation*}
  Thus, $D= (-2)(-2)-(0)(0) = 16>0$ and $f(1,2) = -2<0$. We conclude that the
  point $(1,2)$ is a loal maximum by the second derivative test. The value of
  the local maximum is
  \begin{equation*}
    f(1,2) = 7
  \end{equation*}

  \fl{Boundary $\partial D$:} There are three pieces to the buondary,
  corresponding to the three edges of the triangle.

  Let $B_{1}$ be the horizontal line segement, $B_{2}$ the diagonal segment,
  and $B_{3}$ the vertical segment. We must consider each of these separately.

  \begin{itemize}
    \item For $B_{1}$, we have $y=0$, so the value of the function is
    \begin{equation*}
      f(x,0) = 2+2x-x^{2}
    \end{equation*}
    with $0 \leq x \leq 9$.

    check this). At the point $(1,0)$, the function takes value
    \begin{equation*}
      f(1,0) = 3
    \end{equation*}
    \item For $B_{3}$, we have $x=0$, so the function value is
    \begin{equation*}
      f(0,y) =2+ 4y-y^{2}
    \end{equation*}
    with $0 \leq y \leq 9$. This is another downward opening parabola, which
    is maximized when $y=2$. Thus we have the point $(0,2)$, which has
    function value
    \begin{equation*}
      f(0,2) = 6.
    \end{equation*}
    
    \item For $B_{2}$, we have $y=9-x$. On $B_{2}$, the value of the function

    \begin{align*}

    \end{align*}

    \begin{equation*}
      f(4,5) = -11
    \end{equation*}
    \item We also have to check the corners, as these are the ``boundaries''

    \begin{equation*}
      f(0,0) = 2, \quad f(9,0)=-61, \quad \text{and} \quad f(0,9) = -43
    \end{equation*}
  \end{itemize}
  Putting both interior and boundary analyses together, we have 7 candidates
  for the global maximum, indicated in red:

  We compare the value of the function at each of these points. The point

\subsection{Connection to Physics: Work}
In everyday language, \textit{work} means the total amount of effort required to perform a task. In
physics, it has a techincal meaning which depends on the idea of force. In the simplest case, the amount
of \demph{work} $W$ done by a \textit{constant} force $F$ which moves an object a distance $d$ is
\begin{equation*}
  W = F\times d.
\end{equation*}
Work is measured in \textbf{Joules} (J). We have
$\mathrm{J} = \mathrm{m N} = \mathrm{kg}\times \mathrm{m}^{2}/\mathrm{s}^{2}$. One Joule approximately the amount
of work done to raise a stick of butter vertically one meter:

\begin{equation*}
  W 
  = (\text{force})\times (\text{distance}) 
  = \left( 1\mathrm{N} \right)  \times \left( 1 \mathrm{m} \right) 
  = 1 \mathrm{N} \mathrm{m} 
  = 1 \mathrm{J}.
\end{equation*}

This example assumes that the force and object's motion the are lined up in the same direction. But what
if the direction of motion is different from the direction of the force. For example, a surfer being
